# QQ 面板分区整理

应用版本仍为 1.1.1。只更新可运行测试版，不构建安装包。

导航按用途分为五组：运行与账号、聊天设置、用户与陪伴、内容与日程、系统管理。进入页面时展开所属组，避免所有功能同时挤在长侧栏中；搜索依旧可以直达任意设置。

聊天节奏分为节奏与接话、消息发送、上下文与频率、主动群聊四个分类，替代原来的十几个卡片定位按钮。角色、记忆、主动陪伴、模型、传话与工具权限页面也采用简短的分类页签。支持方向键、Home 和 End 导航。

戳戳与互动成为独立入口，戳戳总开关、预设／AI 模式及冷却放在一起，主页点赞另设页签。提醒有独立页面；原主动陪伴中的定时群聊小报移到传话与分享，与自主分享配置放在同一分类。分享总开关始终可见，聊天记录／日记进入分享草稿时会自动打开手动编辑分类。

所有控件均移动原节点，保留 ID、事件处理、字段类型、开关状态和统一保存流程，不克隆或引入第二份设置。切页保留草稿；搜索会揭示正确分类及尚未启用功能的选项，但不自动打开权限开关。用户列表与档案详情保留各自独立滚动。

版式统一标题、间距、卡片和表单网格。宽内容区域用双列表单，窄区域自动改为单列；清理空布局容器，底部保留统一保存区域，页面切换不使用形变动画。浅色与深色主题沿用现有色板。

验证：

- `desktop/verify-qq-layout.mjs`：实际运行目录中检查唯一控件、分区归属、搜索定位、草稿保留、键盘操作、跨页分享、独立滚动、后端保存，以及 840px／1280px 两种宽度与浅深主题下每个页面和分类的横向溢出。
- `desktop/verify-qq-scroll.mjs`：840／1000／1280px、浅深主题，全部 23 页检查侧栏悬停稳定和滚动无水平溢出。
- `desktop/verify-qq-growth.mjs`、`desktop/verify-qq-extras.mjs`：关系玩法、自定义参数、设置保存、记录分享与新功能入口回归。
