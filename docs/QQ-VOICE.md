# QQ AI 语音回复

Cupbox 1.1.1 的 QQ 机器人在「语音回复 → 让回复有声音」配置。功能默认关闭，与原来的导入语音素材开关独立，不依赖自主聊天工具。

## 使用

1. 准备并运行 GPT-SoVITS 的 `api_v2.py` 服务，加载可用的 GPT / SoVITS 权重。Cupbox 不包含这些模型、运行时或参考录音，不自动下载或启动。
2. 只有中文音色时，将朗读语言设为「中文」，接口默认为 `http://127.0.0.1:9880/tts`。
3. 填写服务能读取的参考音目录，里面放 `calm-reference.wav`。将「对应的完整台词」改成这段录音实际说的话；预填内容适用于参考项目的原声，不能用于任意录音。
4. 点击「生成并试听」，不必登录 QQ，也不必先开启语音开关。试听使用当前草稿，只在本机播放；确认后开启 AI 语音回复并保存机器人设置。
5. QQ 已在线、自动回复已开启时，机器人先发送文字，再补发一条语音。实际语音发送需要 NapCat/OneBot 支持 WAV 转录音。

日文可使用独立服务（默认端口 9881）、目录和台词；自动语言模式遇到假名选择日文，其余选择中文，因此需准备两套配置，不会自动翻译回复。

## 情绪音色

可选「跟随情绪调整语气」，在各语言目录加入 `excited-reference.wav`（开心）、`wronged-reference.wav`（委屈/难过）、`sleepy-reference.wav`（困倦）。始终以 calm 为主参考音，情绪录音作为辅助参考音。日文平静音色可额外使用 `calm-aux-reference.wav`。

本机缺少情绪参考音时，退回主参考音。远程服务上的文件无法在本机校验，开启情绪前请备齐相应文件；目录必须填写服务端路径。

## 发送行为

- 只朗读实际成功投递的文字，沿用文字输出检测；合并本轮分段/自主文字为一条语音。仅发图片或素材语音时不另行生成。
- 清理 Markdown、链接与代码块，避免朗读代码或网址。默认上限 500 字，超长保留完整文字并跳过语音，不截断朗读。
- 默认超时 60 秒，可调 5～90 秒。只接受 8MB 内非空 PCM WAV，不跟随接口重定向。语速可调 0.5～2。
- 语音计入每分钟发送上限；生成繁忙、失败、超时或协议端拒绝均保留文字，不自动重试。停止机器人、关闭开关或修改设置会取消本轮待发语音，已提交的消息不能撤回。
- 配置保存在本机 QQ 设置中；生成音频仅驻留内存，不加入素材库或记忆。服务地址为远程地址时，会向该服务提交回复文字和参考音路径，保存时会提示。

## 实现参考

参考 [lilith1257/dsh-plugin-qq-groupmate](https://github.com/lilith1257/dsh-plugin-qq-groupmate)（MIT）的 [lib/voice.js](https://github.com/lilith1257/dsh-plugin-qq-groupmate/blob/main/lib/voice.js)：GPT-SoVITS api_v2 JSON 请求、中日文独立配置、情绪辅助参考音，以及文字发送后补充语音的行为。Cupbox 使用自身的配置、输出检查、取消和限速流程。

验证：本地模拟 GPT-SoVITS 服务覆盖语言分流、请求参数、WAV 检查、异常与取消、分段合并及发送限速；真实模型音质与 QQ 转码仍需使用者的模型服务和登录账号验证。
