# 欢迎与欢送模板

入口：QQ机器人 → 群聊管理 → 成员与手动 → 欢迎与欢送。

开启群管总开关并保存管理群名单，再按需开启欢迎、欢送。默认都关闭；机器人需在线并具有目标群管理权限。此功能独立于聊天自动回复，不调用 AI；观察模式仅记录，不发送。支持 NapCat / OneBot 接入。

欢迎、通用欢送和被移出群聊可分别填写多行模板（最多500字）。移出模板留空沿用通用欢送。欢送可选全部、仅主动退群、仅被移出。示例预览在本机使用虚拟资料，不向 QQ 发送；点占位符会插入所选模板的光标处，可一键填入示例。

| 占位符 | 含义 |
| --- | --- |
| `{用户}`、`{QQ}` | 用户 QQ 号，兼容原有模板 |
| `{昵称}`、`{群名片}` | 用户昵称 / 群名片，失败时回退 QQ |
| `{@用户}` | 入群时真实 @；离群时显示昵称及 QQ |
| `{群号}`、`{群名}`、`{群人数}` | 当前群的资料，人数无法读取时显示未知 |
| `{操作者}`、`{操作者QQ}` | 事件中邀请者或移出者；没有信息时显示未知 |
| `{机器人}`、`{机器人QQ}` | 当前机器人的昵称及 QQ |
| `{日期}`、`{时间}`、`{星期}` | 事件发生时的北京时间 |
| `{事件}` | 入群、主动退群、被移出群聊或离群 |
| `{入群方式}` | 管理员批准、邀请入群或入群；离群时不适用 |
| `{离群原因}` | 主动退群、被移出群聊或离群；入群时不适用 |

未知占位符按原文保留，预览会提示。替换仅执行一次，昵称和群名里的花括号不会再作为模板执行，不解析 CQ 代码。真实资料按模板需要读取，失败时使用明确回退值；不编造成员人数或昵称。成员离群后可能无法获取资料，此时显示 QQ 号。展开后的文字最多4000字。

仅处理在线期间收到的新事件，忽略过期通知、机器人自身离群和不在名单内的群。沿用群管通知持久化去重、每分钟30次操作上限和停止/设置变更取消机制；发送失败或超时结果未知不自动重试。
