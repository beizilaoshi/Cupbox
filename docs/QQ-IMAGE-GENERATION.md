# QQ AI 生图

入口：QQ 机器人 → 内容与日程 → AI生图。默认关闭。

1. 在主窗口模型库添加绘图服务，勾选“生图”能力，填写 API 地址、密钥、模型 ID 和图片尺寸。
2. 回到 AI生图，选择独立模型、每日上限、冷却和指令前缀，保存底部设置。聊天模型与生图模型互不替换。
3. 面板填写描述，生成后自动保存本机并提供预览。聊天发送目标在“传话与分享”登记，手动发送会核对目标。
4. 私聊发送 `画图 一只蓝色鲸鱼`；群聊发送 `@机器人 画图 一只蓝色鲸鱼`。前缀可自定义。沿用自动回复、会话范围与睡眠设置，不满足触发条件不调用生图服务。
5. 选中图片后点击“加入QQ空间草稿配图”，填写说说正文并保存草稿，再按原有流程发布。也可在空间的配图选择框多选本机生图。

支持 OpenAI 兼容的 `/images/generations`，以及硅基流动的 `image_size` 参数；返回 `data[].b64_json`、`data[].url` 或 `images[].url`。模型库的 API URL 通常应包含 `/v1`。部分厂商异步任务、私有协议和图片编辑接口不在本次范围。

图片最多8MB，解码限制为1600万像素，重新编码为PNG后保存。只提交绘图描述，不附带聊天历史或QQ凭证。服务返回的下载地址按公网HTTPS处理，逐跳阻止私网目标，不转发模型API密钥。文件与索引按机器人配置目录隔离，发送前验证文件类型、大小和内容哈希。

每日额度包含失败尝试，生成不自动重试；结果不明的聊天发送也不自动重发。生图收费通常按张或尺寸计算，消耗统计记录“AI生图”请求次数，未知费用不套用文本token单价。本机最多保留100张索引图片，达到上限会停止生成。

“AI自动发空间时配一张图”另设开关，默认关闭。开启后仍需空间总开关与AI发布模式；AI决定发说说后才生成一张插图，受同一生图预算约束。生成失败停止本次发布，避免无意改变用户选择的图文模式。

带图空间接口已按 [NapCat SendQzoneMsg 源码](https://github.com/NapNeko/NapCatQQ/blob/main/packages/napcat-onebot/action/extends/SendQzoneMsg.ts)核对，使用 `images: ["base64://..."]`。每篇最多9张、总计20MB，实际成功仍取决于当前协议端版本和QQ权限。QQ官方机器人及其他平台入口暂不开放这项QQ专用功能。

验证使用隔离目录与本机模拟绘图接口，实际检查了渲染器→IPC→HTTP→PNG保存预览→空间草稿存储；聊天图片与空间发布RPC由测试协议端校验。没有使用用户的付费密钥测试，也没有向真实QQ联系人发送测试图片或发布测试说说。
