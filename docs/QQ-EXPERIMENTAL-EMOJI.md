# 实验性创新表情

入口：QQ 机器人 → 表情与语音 → 表情模式 → 实验性创新。版本仍为1.1.0，默认模式仍为标准。

先为图片填写含义、画面与动作；带字图需照实填写图上文字。标签和备注可帮助召回。实验黑名单只影响此模式。随后选择独立简报模型和视觉复核模型，保存机器人设置；开启自动回复时需核对额外上传与调用提示。

## 实际流程

1. 明确要求表情或斗图时走原有发送工具；先排除最近十张、已知的来图哈希和实验黑名单，不调用选图模型。群内禁用、总开关、冷却与原有素材授权仍优先。
2. 普通消息先由代码排除解释、报错、步骤、长请求、难过或生气等情境。此阶段不调用模型。长技术回复生成后也不会再追加实验表情。
3. 独立简报模型读取默认15条已有会话记录（可调1～30条），输出send、emotion、scene、text。仍受原上下文保存条数和权限限制；不会因为此设置额外旁听。简报失败只做一次缩短上下文的兜底，再失败则结束。
4. 文字路检索图上文字/标签/备注，画面路检索画面/情绪。相关性采用本机查询词覆盖率：中文相邻双字词及英文词中，候选包含的查询词数除以查询词总数。两路各取前四，合并按内容哈希去重，默认保留最多六张；选八张拼图时最多保留八张。默认最低相关性0.25。带字意图若没有图上文字达到相关性门槛，直接不发。
5. 默认使用四张2×2拼图，可选六张2×3或八张2×4。每个图片区域360×360像素，下方附卡片文字；动图最多采样四帧。顺序由可记录种子随机打乱。
6. 视觉模型每次只接收一张编号拼图，必须输出选第几张、实际读到的原图文字、情绪、动作、理由和0～1置信度。编号与下方卡片说明不属于原图OCR内容。单次严格限时两秒。
7. 选择0、置信度低于0.6、OCR与卡片不一致、无字图缺少情绪或动作理由、明显指令/嘲讽/自我否定/话题冲突、坏格式、图片读取失败、超时，均不发图。OCR先规范化空白与标点，支持至少85%的编辑相似度；这是启发式保护，不是内容准确性的保证。
8. 私聊、被@或本会话首次发图时，对同一组候选反序再问一次。按图片身份而非编号比较，两次不同就标记位置偏差并不发。
9. 等待选图开启时先选好图，再生成文字，文字发出后一秒发图；关闭时文字与选图并行，图选好后隔一秒补发。停止、设置变化、内容检测拦截或模型选择跳过，都会阻止后续图片。聊天模型不开放图片选择工具，也不生成表情标记。
10. QQ确认回执后，在本会话记为“表情包：图上文字＋实际画面”。失败和未知回执不写成成功，不自动重试。保留对话和是否落盘继续遵循原记忆设置；最近十张去重状态单独按账号、群/私聊保存，未知回执也避免立即重发。

## 本机记录与边界

普通日志仅保留阶段、图片ID、原因、种子和耗时等，不记录聊天正文或图片数据。详细实验记录默认关闭；开启后明文保存在本机文档Cupbox/qq-bot目录，最多20轮，包括简报、候选相似度、实际拼图、候选顺序、种子、结果、回执、耗时和可取得的用量。上游没有返回完整用量或未设置价格时，费用显示未知，不按零费用处理。查看入口在实验模式设置内。

对方来图只按协议事件中已有的MD5/SHA256/文件哈希与本机图库比较，不会为了猜同款而下载未授权来图。无法取得哈希时不能保证识别同款。视觉识别和启发式安全检查也可能出错，因此该模式保持实验标签；慢视觉服务在两秒门槛下可能经常不发图。
