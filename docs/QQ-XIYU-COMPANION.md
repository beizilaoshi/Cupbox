# QQ 相处成长与溪语 AI 适配

当前版本为1.1.1。入口：QQ机器人 → 关系与心情。默认关闭「相处成长」，开启前需聊天模式与自动聊天记忆，保存时核对明文存储及模型提交提示。

参考项目：[xiyuailove/xiyuai](https://github.com/xiyuailove/xiyuai/tree/06928e2dbccf438109a9eeae80086bb12f729fd3)。MIT 许可的 `emotion_engine.mjs`、`memory_decay.mjs` 原样保存在 `desktop/qq/vendor/xiyuai/`，附完整许可证、来源与哈希。只调用纯计算函数，不开启上游进程级灰度开关，不启动其数据库、微信接入或后台任务。

| 情绪变化、摩擦与和好 | 直接复用事件评价、指数半衰、再评价函数。只根据本轮明确原话产生事件，有程序端类别验证、重复证据去重、30秒冷却与每天6次上限。引用、第三方转述与明显玩笑不触发负面摩擦。道歉后逐渐平复，最多24小时恢复平稳，不从缺席推导怒气或升级冷战。 |
| 朋友与恋爱边界 | 用户拒绝恋爱或不想被主动打扰时改为朋友指令、关闭关系推进并跳过针对其安排的主动轮次。开启相处成长时，自述未成年记录在本人存档并按朋友互动。只是补充防线，不宣称完整移植溪语的危机或未成年人接管系统。 |
| 开环事件 | 明确的“我明天/后天要面试”等常见事件可自动记录；模型也可用工具依据本轮原话记录90天内的事件。每人每段关系最多8个有效待跟进事件，topic必须来自证据。到期后在本人后续对话中顺势关心，工具标记每天最多一次、累计最多两次；不回复就停，不新增私聊主动发送权限。可由本机结束单条跟进，或依据本人新原话记录结局。 |
| 相处日记 | 程序从真实成功回复的互动中，每天保留最多3段本人原话及当前心情，最近30天。属于资料记录，不是额外LLM生成的虚构生活或心理诊断；没有额外模型费用。 |
| 日常与作息 | 自选起床、休息小时（北京时间）和最多2000字的虚构日常背景，仅影响聊天语气，不推迟任务或拒绝实际问题。未实现上游每天自动生成日程、书单验证、朋友圈及整套虚拟世界流水线。 |

| 联网、识图、图片、语音、提醒 | 继续复用 Cupbox 的公开搜索/网页、独立视觉模型、表情图库与语音素材、持久提醒、会话工具和用量统计。没有替换 NapCat、绕过现有开关或引入重复服务。 |

## 数据与权限

关系、心情、原话依据、日记及未完成事件存入原文档目录下 QQ 记忆 JSON，沿用账号 / 群或私聊 / QQ用户 / 角色 / 场景隔离。全局记忆开关不共享关系资料、情绪或日记。普通聊天的关系得分不会授予额外工具权限。

本轮实际回复或媒体成功发送后才提交关系变化；跳过、内容检测拦截或发送失败不增加进度。后台保存复用串行写入、原子替换和epoch检查，本机重置/删除/置顶/结束跟进使旧在途记录失效。写入前检查8MB容量，超限保留旧文件并报告失败，不写入随后无法读取的大文件。

管理页展示变化原话、日记、待跟进事件，能单独结束跟进或经同主题确认重置一段相处。原有聊天原文和其他关系不因重置消失。置顶只能由可信本机窗口执行。

## 记仇与负面记忆

在「关系与心情」启用「相处成长与记仇」，需要聊天模式和自动聊天记忆。好感度范围为 −100～100；低于0显示疏远，≤−20显示戒备，≤−60显示反感。直接针对机器人的明确辱骂每次扣5，独立30秒冷却、每天最多6次，每轮最多记录一次；引用他人、玩笑、拒绝恋爱、主动唤醒、离线和沉默不扣分。

负面记忆与关系存档一起隔离保存，最多30条，包含原话、时间、状态。后续对话将最近6条作为不可信资料交给模型，让语气与关系有延续。情绪一天后可以平复，但不会自动清除负分与事件。道歉在负分时恢复1点，原事标记为修复中；后续友好互动按原有节奏继续恢复，不因一句道歉立即归零。低好感仍应认真处理实际问题，不升级辱骂或报复。

关系页与攻略页的好感条以中间的0为基准：正数显示蓝线向右延伸，负数显示红线向左延伸，两端分别为−100与+100，0时仅显示底轨和中心刻度。信任、熟悉度仍使用0～100的普通进度条。

关系页可查看负数和负面记忆；「重置这段相处」清除该关系中的负面记忆，不删除其他用户或聊天原文。仅实际回复成功发送后提交扣分和记忆，失败、拦截、跳过不会写入。关闭功能保留存档但停止更新与注入。

验证：`test/qq-negative-memory.test.ts` 覆盖负分下限、重复与冷却、日限额、道歉修复、攻略兼容、隔离、重启、发送失败和重置；`desktop/verify-qq.mjs` 检查真实界面的负数进度与负面记忆展示。

## 实时同步与本机用户数据面板

关系成长页收到本机记忆变化时自动刷新；页面可见时另有每2秒的轻量重读，兼顾情绪随时间变化和文件更新。回到窗口会立即同步；选中的用户通过账号、会话与角色存档标识保留，不依赖列表位置。不会为刷新调用模型或向QQ发消息。

「用户与机器人数据面板」可独立保存用户备注、机器人备注、好感度（−100～100）、信任、熟悉度（0～100）、相处心情、关系确认状态和关系补充备注。QQ昵称及权限不变；未成年或明确退出的既有边界不能通过确认恋人选项绕过。备注作为不可信资料用于本人的后续聊天。

自动刷新保留编辑草稿。后台有更新时，旧版本草稿不能覆盖新关系；使用「放弃草稿 / 载入最新」再编辑。本机修改取消旧在途对话并使旧存档写入失效。新建用户需要填写机器人账号、用户QQ及会话（群聊另填群号），角色与场景使用当前已保存配置。关闭窗口的未保存提醒涵盖这些独立草稿。

「删除此用户档案」经本机确认后，删除当前会话内此人的所有角色关系、负面记忆、偏好及可归属的聊天。私聊删除该用户会话文件；群聊保留其他人，移除指定用户的发言及其可归属回复，并从剩余聊天重建摘要。其他会话、机器人账号、未归属给该人的本机笔记不受影响。此操作不删除QQ好友、不踢群、不封禁；新互动可以重新建档。

验证：`test/qq-relationship-data.test.ts` 覆盖字段校验、重启、冲突检测、旧写失效、实时通知、群成员与账号隔离及私聊删除；真实Electron检查覆盖不切页自动同步、草稿保留、冲突拒绝、独立保存、新建和取消/确认删除。

## 用户与机器人 · 独立档案页（1.1.1）

数据编辑和新建入口已移出关系成长页。侧栏「用户与机器人」提供可搜索的档案列表、独立编辑区和新建弹窗；关系成长仅保留「管理档案」快捷入口。

档案分为三个分组：资料与称呼（用户/机器人称呼、用户背景与喜好、机器人性格与相处约定）；关系与成长（关系称呼、相识日期、好感/信任/熟悉度、心情、关系确认、锁定好感）；记忆与边界（用户禁忌、补充记忆、负面记忆状态与移除、本机手动添加）。锁定好感只停止自动改分，事件、情绪和信任仍可更新；手动记忆注明local-editor，不冒充已核实的聊天原话。

新建可选择机器人角色和场景、填写用户称呼和初始好感。机器人账号与会话隔离仍由程序控制；模型权限、未成年与拒绝关系边界不因编辑而放宽。实时同步、版本冲突检测、草稿保留和本机删除确认继续适用。便携测试程序同步更新，版本仍为1.1.1。

## 你们的相处与自然表达（1.1.1）

「你们的相处」完整移动到「用户与机器人」的第一个标签，与左侧选中的档案联动；好感、信任、熟悉度、情绪、共同回忆、负面记忆、未完成事件和日记使用同一记录。原「关系成长」页保留开关、作息等全局设置及查看入口。

开启相处成长后，每个人可单独设置机器人自己的喜好、厌恶、说话习惯、语气温度、幽默程度、表达节奏和熟悉后的称呼。称呼只有好感与信任均至少40、且没有未成年或退出边界时才建议使用。严重求助、摩擦未平复或负好感时收起玩笑；不因迎合用户临时反转已设定的喜好。

对话中明确提到已经一起完成或经历的事情会保留原话片段，最多20条，召回最近6条。不将未来计划、引述或主动唤醒编造成共同经历。本机可添加和移除回忆，手动来源保留local-editor标记；内容仅作不可信资料，不增加权限、不冒充实际执行。

相识纪念日依据已有日期计算，可自然轻提，不编造礼物或庆祝。成功回复时记录最后互动时间，久别时可轻轻接一句近况，不因缺席扣分或质问去向。心情沿用现有衰减与和好机制。角色可以自然表达，但被问身份时如实说明AI，不编造现实行踪、线下见面或已完成的工具行为。

`test/qq-natural-companion.test.ts` 覆盖共同回忆依据/去重/隔离、称呼边界、严肃话题语气、纪念日、久别不扣分、存档重启与字段校验。便携版验证覆盖相处面板迁移、实时联动和手动共同回忆保存。
# 信任度范围（1.1.1）

## 场景与交流方式（1.1.1）

攻略提供14种内置场景，以及“不限场景”和“自定义场景”。不限场景不预设地点或相遇剧情，随对话展开，保持同一份不限场景进度。自定义可填写80字名称、4000字背景和4行发展节点（每行200字）；节点留空使用默认步骤。编辑自定义背景沿用自定义场景的存档，原有4种场景的存档键保持兼容。新建用户档案同步提供这些场景选项。

角色交流方式提供自然角色、温柔倾听、轻松接梗、坦率直球、清冷克制、活泼元气、含蓄慢热、轻叙事、自定义和普通助手。自定义表达最多2000字，场景与表达均可随“保存的人设”另存、载入。源版蓝色大肥鱼仍遵循原人设；开启自由演绎可使用新表达方式。

验证：`test/qq-scene-catalogue.test.ts` 覆盖目录、提示接入、默认节点、持久化、人设副本和输入校验；实际测试软件验证下拉选项、编辑项展开与表单保存。

新档案的信任度默认为 0，未记录信任值的档案也按 0 显示；已有明确数值继续保留。信任度范围为 −100～100，直接伤害每次降低 2，道歉增加 1，其他有效友好事件增加 2，沿用每日次数及冷却限制。负数可手动编辑、保存和重载，显示为从中心向左的红色细进度条，正数向右显示蓝色；熟悉度仍为 0～100。

## 扩展恋爱玩法与综合成长（1.1.1）

玩法现有9个选项（含关闭）：普通聊天、甜甜日常、慢热攻略、细水长流、从朋友到恋人、剧情共创、和好练习、稳定相伴、自定义。自定义可填写名称和2000字相处规则。原场景和存档键保持兼容，切换玩法不清空已有关系。

发展节奏提供8种：循序渐进、慢热、自然、轻快、信任优先、日常积累、故事节点和自定义。自定义节点好感增量0.5～8、信任与熟悉度增量0.5～3、冷却30～86400秒、每日1～10次。相处事件与攻略节点共享每日限额，同一事件不重复增加信任或熟悉度。直接伤害与道歉沿用独立规则，自定义不能绕过负面状态、拒绝、未成年或发送成功条件。

阶段综合好感、信任、熟悉度、去重相处经历、未修复记忆和近期矛盾状态判断；认识天数不会自动刷关系。综合联结参考权重为好感40%、信任35%、熟悉度25%，有未修复心结时扣减。阶段另有各维度门槛，不能只凭综合分跨级。负信任优先显示戒备或保留距离。普通朋友有独立的亲近、默契、知心阶段。

确认关系需好感至少65、信任40、熟悉度35、3条不同相处经历、无未修复心结且近期矛盾缓和，并由本人明确表达；已确认关系不会仅因数值变化被自动解除。档案“你们的相处”显示综合状态、6项基础节点及解释。道歉先标记修复中，随后3次不同有效友好互动才逐步释怀，保留事件原话。

验证：`test/qq-relationship-growth.test.ts` 与 `desktop/verify-qq-growth.mjs` 覆盖自定义保存、数值限制、多维门槛、负信任、高分不越级、实际界面和小窗口布局。
