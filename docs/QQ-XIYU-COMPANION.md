# QQ 相处成长与溪语 AI 适配

版本仍为1.1.0。入口：QQ机器人 → 关系与心情。默认关闭「相处成长」，开启前需聊天模式与自动聊天记忆，保存时核对明文存储及模型提交提示。

参考项目：[xiyuailove/xiyuai](https://github.com/xiyuailove/xiyuai/tree/06928e2dbccf438109a9eeae80086bb12f729fd3)。MIT 许可的 `emotion_engine.mjs`、`memory_decay.mjs` 原样保存在 `desktop/qq/vendor/xiyuai/`，附完整许可证、来源与哈希。只调用纯计算函数，不开启上游进程级灰度开关，不启动其数据库、微信接入或后台任务。

| 参考能力 | QQ 实际适配 |
| --- | --- |
| 好感与关系阶段 | 复用原有 `romances` 存档的唯一 `score`。普通朋友模式也会成长，显示好感、信任、熟悉度、认识天数；攻略开启时由原有攻略工具控制分数，陪伴事件只更新其他维度，避免双计分。没有默认互相暗恋或自动确认恋人。 |
| 情绪变化、摩擦与和好 | 直接复用事件评价、指数半衰、再评价函数。只根据本轮明确原话产生事件，有程序端类别验证、重复证据去重、30秒冷却与每天6次上限。引用、第三方转述与明显玩笑不触发负面摩擦。道歉后逐渐平复，最多24小时恢复平稳，不从缺席推导怒气或升级冷战。 |
| 朋友与恋爱边界 | 用户拒绝恋爱或不想被主动打扰时改为朋友指令、关闭关系推进并跳过针对其安排的主动轮次。开启相处成长时，自述未成年记录在本人存档并按朋友互动。只是补充防线，不宣称完整移植溪语的危机或未成年人接管系统。 |
| 开环事件 | 明确的“我明天/后天要面试”等常见事件可自动记录；模型也可用工具依据本轮原话记录90天内的事件。每人每段关系最多8个有效待跟进事件，topic必须来自证据。到期后在本人后续对话中顺势关心，工具标记每天最多一次、累计最多两次；不回复就停，不新增私聊主动发送权限。可由本机结束单条跟进，或依据本人新原话记录结局。 |
| 相处日记 | 程序从真实成功回复的互动中，每天保留最多3段本人原话及当前心情，最近30天。属于资料记录，不是额外LLM生成的虚构生活或心理诊断；没有额外模型费用。 |
| 日常与作息 | 自选起床、休息小时（北京时间）和最多2000字的虚构日常背景，仅影响聊天语气，不推迟任务或拒绝实际问题。未实现上游每天自动生成日程、书单验证、朋友圈及整套虚拟世界流水线。 |
| 记忆淡化 | 直接复用上游快/中/慢半衰与召回评分，按相关性与记忆新近程度调整排序。聊天片段作为较轻记忆，偏好较重要；不删除文件。自动记忆页可以本机置顶偏好，置顶不衰减，模型无置顶或删除权限。 |
| 联网、识图、图片、语音、提醒 | 继续复用 Cupbox 的公开搜索/网页、独立视觉模型、表情图库与语音素材、持久提醒、会话工具和用量统计。没有替换 NapCat、绕过现有开关或引入重复服务。 |
| 网页账号、微信部署、支付、肖像生图、TTS/ASR、Inner OS、每日后台批处理 | 不属于本轮已实现功能。上游Web/微信服务不能直接作为QQ插件运行；独立的媒体生成服务与后台模型任务还需新的配置及费用控制，界面不会冒称已开启。 |

## 数据与权限

关系、心情、原话依据、日记及未完成事件存入原文档目录下 QQ 记忆 JSON，沿用账号 / 群或私聊 / QQ用户 / 角色 / 场景隔离。全局记忆开关不共享关系资料、情绪或日记。普通聊天的关系得分不会授予额外工具权限。

本轮实际回复或媒体成功发送后才提交关系变化；跳过、内容检测拦截或发送失败不增加进度。后台保存复用串行写入、原子替换和epoch检查，本机重置/删除/置顶/结束跟进使旧在途记录失效。写入前检查8MB容量，超限保留旧文件并报告失败，不写入随后无法读取的大文件。

管理页展示变化原话、日记、待跟进事件，能单独结束跟进或经同主题确认重置一段相处。原有聊天原文和其他关系不因重置消失。置顶只能由可信本机窗口执行。

## 验证

`test/qq-romance.test.ts` 验证好感与攻略不双计分、原话/参数验证、亲密边界、离线不降分、情绪半衰、无永久冷战、开环次数、关闭事件与旧写失效、记忆置顶和成功发送后才保存。

`desktop/verify-qq.mjs` 使用隔离数据验证实际界面的开关保存、风险提示、关系数值/证据/日记/开环展示、本机关闭跟进、偏好置顶和小窗口布局。所有测试使用本机模型/QQ桩，不登录真实QQ或调用付费模型。具体文字风格仍受模型与本机人设配置影响。
