## 试聊的实际范围

- 使用当前账号已保存的模型、表达、人设和分段设置；未保存草稿不生效。
- 本次运行内保留最多60条展示记录；上下文条数遵循已保存设置。保存设置或更改模拟范围后开始新会话。
- 使用独立 BotEngine 和只捕获文本的发送端，不持有真实机器人发送器、长期记忆或关系存储，不参与真实群聊/私聊收发。
- 真实用户记忆、好感、恋爱进展、语音、图片、联网、本机工具和主动行动不参与试聊；不受自动回复开关和睡眠时间限制。因此不能把试聊当作全部 QQ 功能的端到端测试。
- 可填写模拟群号/QQ号，选择限定知识范围；只影响范围筛选及对应的会话表达预设，不查询联系人或发送消息。知识总开关和文档启用状态仍生效。
- 输入会发给所选模型并消耗额度；正常记录模型用量，试聊正文不落入真实聊天/记忆文件。记录中的机器人身份使用独立虚拟标识。
- 输出使用同样的安全检测与插件过滤；停止清空会中止生成，迟到结果不得重新出现在面板中。

## 知识检索范围

按当前会话范围和文档启用状态过滤后再建索引，避免其他会话的私有资料影响候选或排序。中英文词项、标题/章节权重、BM25、完整短语加分，单段最多850字符并保留80字符重叠；单份文档最多返回两段，总共最多六段。缓存键覆盖正文与权限，编辑或停用立即影响后续检索。

这是词项检索，不依赖额外付费嵌入模型，也不声称提供语义向量检索。同义词改写仍可能漏检；分数只可比较本次问题内的候选，不代表答案正确率。模型可引用文段出处，但仍需核对答案。

## 验证

新增试聊隔离、上下文、停止、并发、输出拦截、知识排序、来源偏移、权限与缓存变更测试。另有 `desktop/verify-qq-chat-lab.mjs`：隔离本机配置和模拟模型接口，通过真实窗口、预加载与 IPC 测试两轮聊天、用量显示、引用、清空及最小窗口排版，不登录 QQ、不发真实消息。
