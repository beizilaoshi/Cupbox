# 关于页：筑梦喵的像素小房间

V3 已补充家具融合场景与连续动作，见 [场景、动作和生成记录](ABOUT-ROOM-GENERATION-V3.md)。

V4 重绘角色比例与服装视图，加入起身、转向、入座衔接；后续移除导致扭曲的网格形变，改用完整绘制姿势，见 [素材与提示词记录](ABOUT-ROOM-GENERATION-V4.md) 和 [步态素材原提示词](ABOUT-ROOM-WALK-POSES-V4.md)。

后续修正重复色罩、角色局部补光及阴影方向，见 [光照修正与验证](ABOUT-ROOM-LIGHTING.md)。

当前 V5 改用家具碰撞寻路和落脚深度遮挡，三套服装都使用新步态帧，角色改为保留透明度的逐像素 RGB 调光，见 [实现、验证与素材提示词](ABOUT-ROOM-V5.md)。

入口：设置 → 关于与更新。原有版本号、检查更新和仓库链接保留在房间下方。

V2 已根据筑梦喵原立绘通过内置生图重做，见 [素材与完整提示词](ABOUT-ROOM-GENERATION-V2.md)。房间用本机 Canvas 分层渲染生成素材，不联网、不调用模型，也不会修改桌宠的好感、饱食度或作息。

- 每次进入随机选择活动，结合当地时段调整概率；开启“自在生活”后约45秒换一个活动。手动安排的活动至少保留90秒。
- 12种活动：电脑工作、吃饭、睡觉、闲逛、阅读、喝茶、浇水、伸懒腰、看窗外、逗猫、摇摆和收拾房间。闲逛会在前方地板区域走走停停；换活动时走向目标位置。
- 7处可用鼠标或键盘操作的家具：电脑、餐桌、床、书架、绿植、窗户和小猫。也可使用活动下拉框、随机活动、摸摸头、台灯开关。
- 光照按电脑当地时间更新：05:00早上，11:00中午，13:00下午，17:00黄昏，19:00晚上，00:00凌晨。页面开启时持续更新，跨时段无需刷新。
- “布置小房间”可预览六种光照，选择晴空／听雨／飘雪、蓝缎樱花裙／睡衣／学院服，或关闭动作动画。光照预览在下次进入时恢复跟随现实时间；窗外天气是装饰。
- 穿搭、窗外景色、台灯、自在生活和动画偏好自动保存在本机。动画尊重系统减少动态效果偏好；离开页面、关闭设置或隐藏窗口后暂停绘制。

验证：`node_modules/.bin/electron.cmd desktop/verify-about-room.mjs`，在隔离资料目录启动实际测试程序，检查时段边界、实际时钟变化、家具行走、随机活动、互动、设置持久化、后台暂停、最小窗口和渲染错误。截图保存在 `output/about-room-review/`。
