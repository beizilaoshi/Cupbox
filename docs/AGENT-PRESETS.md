# Agent 预设与既有功能适配

在聊天区点击当前预设名称，或进入设置 → Agent 预设。选择预设会切换到执行任务模式，下次发送时生效；正在对话或运行工具时不能切换。设置、模型选择、思考深度及多模型工作流分别控制自己的配置，预设不会自动更换模型或提高权限。

标准、代码和创造预设使用现有工具授权流程；选择代码或创造不代表已经生成文件、运行测试或制作媒体。主对话和工具箱中的手动 AI 入口使用相同预设，历史回复记录实际使用的预设 ID。

三月七预设负责分析本地配置、任务和日志。实际启动从三月七工作流面板完成，不授予聊天模型通过终端、HTTP、桌面操控或文件写入绕过该入口的能力。

渗透预设负责读取本地代码、配置和测试证据，保留只读分析工具。主动渗透测试仍从本机渗透测试 Agent 入口运行，目标固定为 **127.0.0.1**，由用户确认端口。切换预设不会开启扫描、扩大目标、开放通用联网或代码执行。

预设卡片中的配置按钮连接对应功能，模型和安全开关保持独立。未知的旧预设 ID 在读取时回退标准模式；保存未知 ID 会报错。
