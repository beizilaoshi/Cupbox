# 鲜活表达（1.1.1）

QQ 工作台「角色设定 → 更像在和一个人聊天」。默认开启鲜活表达，粗口尺度和吐槽方式默认结合人设判断，可单独改为不用粗口、偶尔感叹、允许爆粗，以及轻轻打趣或嘴损一点。

普通聊天、主动私聊与群聊趣事生成均使用同一套表达偏好。早晚安、催睡和日记收敛粗口；工作模式与明确选择的助手交流方式不加入这层角色口吻。

- 允许短句、不同意见、嘴硬、不满、吐槽、接梗和自然反问；减少固定安慰、客服开场、复述情绪、机械追问与每轮总结。没有要求每句话都幽默、粗俗或短成固定模板。
- 自动尺度参考当前人格、自定义性格、当前关系的机器人性格与说话习惯。鲸鱼娘/毒舌风格可以更直接，安静/慢热风格通常克制；人设明确不说粗口时，自动模式尊重这一点。
- 熟悉且有信任时少些客套；信任或好感为负时可以表达距离和不满，不突然变成撒娇。认真求助、对方不想开玩笑或当前个人边界不喜欢被怼时收敛。
- 鲸鱼娘源版文件和授权原样保留。运行时按当前本机设置放宽粗口检查，允许普通粗口、不把它们统一改回礼貌用语；其余检查仍生效。鲜活模式也放宽源版60字/两句的固定节奏，保留重复与明显啰嗦检查。关闭鲜活表达时使用原来的检查尺度。
- 普通聊天保持角色，不反复解释 AI 身份；明确问到真实身份时如实回答，不伪造现实行程或共同经历。语气选择不改变消息范围、文件权限、输出检测和关系存档。

这些选择会随「保存当前人设为副本」一起保存。已有配置缺少新字段时，默认开启鲜活表达与自动人设尺度。实际措辞由所选模型生成，本机不靠随机插入脏话或固定句子伪装自然。
