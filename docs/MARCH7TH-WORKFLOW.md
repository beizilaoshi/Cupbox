# 三月七工作流

在 Cupbox「设置 → 三月七工作流」选择本机 `March7th Assistant.exe`，选择任务后保存或运行。不能选择 `March7th Launcher.exe`；应先使用 Launcher 完成首次安装、更新、游戏与任务配置。需要管理员权限时，请以相应权限启动 Cupbox。

支持完整运行、日常、每日实训与奖励、体力、模拟宇宙、差分宇宙、货币战争、混沌回忆、虚构叙事、末日幻影、锄大地与兑换码。选择「小助手自定义流程」时填写在小助手中已创建的流程名称。具体任务行为和完成后动作以小助手本地配置为准。

Cupbox 通过上游公开的 CLI 接口启动独立安装的程序，不内置其 Python 实现、游戏素材或运行环境。上游项目：https://github.com/moesnow/March7thAssistant （GPL-3.0）。参数依据其 `main.py`：任务 ID 或 `--workflow-name NAME`。后续上游版本若改变接口，需要同步适配。

任务运行不依赖 AI 模型，日志在设置中展示，最多保留最后 60,000 字符。停止会结束启动的小助手进程树；关闭 Cupbox 也会停止该任务。小助手自行提权产生的进程、单独启动的小助手和游戏进程应在小助手中核对与管理。进程返回 0 仅表示程序正常退出，并不能证明游戏任务实际完成。

Cupbox 在初始化服务前获取 Electron 单实例锁，重复启动会退出新进程并还原、显示和聚焦原窗口（包括已隐藏到托盘的窗口）。锁由 Electron 在进程退出后释放；单实例范围为同一用户会话和同一应用配置目录。

## 与现有功能衔接

三月七预设的「配置工作流」按钮连接此面板；聊天模型只负责分析，不能代替用户启动，也不能通过通用终端绕过确认。配置只从专用保存接口写入，拒绝 Launcher、其他程序名、任意附加参数及含控制字符的自定义流程名称。

每次启动都使用 Cupbox 同风格风险弹窗，明确程序、任务、自定义流程以及可能占用鼠标键盘、消耗资源、执行小助手中配置的完成后动作等影响。沙箱模式不启动真实游戏自动化。Windows UAC 属于操作系统提示，Cupbox 不自动提权。

确认后撤销桌面协作会话；任务运行或等待确认期间不能另行授权桌面控制。运行时可在底部状态栏查看日志与停止任务，**Ctrl+Alt+F12** 请求停止启动的进程树；快捷键不可用时不启动。停止只针对当前启动的进程树，不撤销已经发生的游戏操作，也不能保证控制自行提权或脱离进程树的实例。

取消确认不会启动。停止会取消仍在准备中的启动；停止超时或失败时保留运行状态并允许重试。退出时等待停止结果，失败则保持 Cupbox 打开并显示原因。重复停止不会并发发送多次进程树终止请求，旧进程的延迟日志与关闭事件不会污染下一次运行。

日志可手动复制，分享前应检查账号与其他隐私。测试使用模拟子进程与隔离配置，不自动启动真实游戏。
