# 聊天记忆共享范围

入口：QQ机器人 → 用户与陪伴 → 记忆管理 → 机器人自动记忆 → 哪些聊天可以共享记忆。

- 各会话独立：原有默认设置，每个群和每个私聊独立。
- 群间共享：保留原有模式，允许的群之间召回相关资料，私聊独立。
- 全局共享：同一机器人账号的允许私聊与群聊共享聊天片段、原话偏好及近期聊天资料，已有记录也可参与召回。

选择后保存设置。不同用户保留QQ身份与来源标记，不把一个人的偏好当成另一个人；机器人账号、其他平台工作区仍分别管理。关闭的私聊、私聊黑名单及非允许群不作为跨聊天来源。聊天内容不能自行改变共享模式。

原始会话文件保留，不破坏性合并。近期共享资料有来源、角色、发言者和时间标记，按现有记忆预算输入模型；原会话历史、存档及管理操作继续使用原目标记录。切回独立模式后停止跨聊天召回，旧文件保留。

自动化覆盖私聊→群聊、群聊→私聊、不同私聊、跨账号拒绝、旧模式隔离、来源名单过滤以及新模式设置保存。独立Electron页面验证三种选项、原默认值、保存后重读、窄宽窗口及无界面错误，不启动QQ连接或发送消息。
