# Cupbox 客服助手（1.2.1）

Cupbox主项目聚焦专业工具箱。完整机器人已独立为 [Cupbox-QBOT](https://github.com/beizilaoshi/Cupbox-QBOT)，并非删除；独立版使用自己的账号与数据目录，不自动迁移旧数据。

## 配置顺序

1. 在主窗口模型管理配置文字模型，必要时配置视觉模型。
2. 打开侧栏“客服助手”，选择账号工作区和连接方式。个人QQ扫码使用NapCat；官方QQ、微信、企微、飞书、钉钉沿用已接入连接方式及平台要求。
3. 在“客服接待”设置群/私聊白黑名单、触发关键词、模型、回复频率。首次升级时自动回复关闭，请审核后再开启。
4. 维护店铺名称、人工联系方式及业务政策；在“商品管理”维护名称、价格、规格、库存说明、HTTPS购买链接、售后说明，审核后上架。最多200个商品。每轮优先提供名称命中的商品及其余已上架资料，最多30条；大目录建议商品名称明确并补充业务知识。
5. “业务知识”维护FAQ，可限定允许使用的群号或私聊用户号。正文只作为业务事实，不授予操作权限。
6. “运营与定时”配置目标与正文，人工确认后发送或建立计划。

## 定时发送

本版本仅个人QQ/NapCat支持主动运营消息，其他平台保留客服被动回复，不承诺平台未开放的主动能力。支持一次性、每日、每周；每日/每周时间为北京时间，一次性日期选择器使用当前电脑时区。最多100个任务，每条正文最多3000字。

计划绑定QQ账号；接收目标须通过客服范围检查。需要应用运行、账号在线、自动回复开启。每15秒检查到期任务，超过一分钟的任务标记错过，不补发；周期计划只安排下一期。发送前持久化占用状态；重启发现发送中状态记为结果不明，不自动重试。平台确认提交不等于最终送达。请先征得接收方同意，不用于紧急、关键通知。

用户手动维护价格、库存、政策，不连接实时订单、库存或支付系统。缺少依据时引导人工，不声称退款、下单或人工已经接管。

## 数据与安全

每个账号工作区的`qq-bot/customer-profile.json`、`customer-products.json`、`customer-jobs.json`保存业务资料、商品和任务记录。聊天可按已有会话记忆设置保存；不要填写密码、验证码、密钥等秘密。

娱乐配置在服务端锁定，不会因旧配置为开启而恢复恋爱、陪伴、点歌、日记或主动闲聊。本版不删除旧用户文件，也不开放客服访问任意本地文件/终端。主项目保留少量底层兼容模块以复用连接和存储，完整机器人功能应前往独立项目使用。
