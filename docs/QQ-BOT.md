# QQ 机器人（Cupbox 1.1.0）

主窗口侧栏 → **QQ 机器人**。重复点击会复用同一个机器人窗口。
最小化继续运行；关闭机器人窗口或退出应用会停止协议端、取消回复并清除运行上下文。

## 接话与语气适配

- **角色设定 → 用对话示例教语气**：最多6组“对方/机器人”示例，支持参考示例、改写和移除。示例仅用于学习表达，不作为实际历史、事实或工具授权；会增加少量输入token，不增加模型调用轮次。原版蓝色大肥鱼不叠加自定义示例，需开启自由演绎才使用。
- **聊天节奏 → 每个会话的聊天节奏**：按群号或私聊QQ设置。少打扰关闭本会话的免@接话和主动插话；认真回答在此基础上采用详细表达；熟人闲聊采用口语表达并沿用全局触发范围。全部只在聊天模式应用，不改变模型、旁听、白名单、联网、本地文件或主动发言授权。源人设仍保留原表达，独立节奏的限制继续生效。
- **聊天节奏 → 更自然地接住话题**：配合自然聊天，通过有限的近期回复识别短句接话、倾诉、道别和实际问题，提醒模型少重复开场、少机械追问；可关闭。只参考当前发言者的可见偏好，不把其他群友的要求套给本人，不自动修改长期记忆，不对生成内容做粗暴删词。实际表达取决于所选模型，未进行真人感效果保证。

上述编辑点击“加入设置草稿”后仍需底部“保存所有设置”才能生效。尚未加入的示例文本与会话编辑也计入关闭提醒；已加入的草稿使用原有跨页保存与放弃流程。

参考来源：[AstrBot语气示例](https://github.com/AstrBotDevs/AstrBot/blob/master/dashboard/src/i18n/locales/en-US/features/persona.json)、[Amadeus分群配置](https://github.com/RoggeOhta/amadeus-in-shell)、[MaiBot群聊逻辑优化](https://github.com/Luoyehe/Maibot-group-chat-logic-optimizer)。这些功能按现有Electron/OneBot架构独立适配，未复制整套Agent或引入第二份人格、记忆与权限管理。

## 第一次使用

1. 先在主窗口“模型管理”配置文本模型；需要看图时再配置视觉模型。
2. 打开机器人窗口，在“人格与能力”选择对话模型、温度、思考深度和聊天人格，保存。
3. 点击“准备并启动”。首次从 NapCat 官方 GitHub 下载固定版本的 Windows Node 运行包，约 118 MiB，自动校验、解压、配置本机端口与随机认证令牌。
4. 软件中出现二维码后，用机器人账号的手机 QQ 扫描并确认。QQ 的手机确认或设备验证需要账号本人完成，应用不绕过验证。
5. 在“消息与节奏”选择所有群、白名单或黑名单，设置 @ / 关键词及私聊规则。登录后可刷新实际群列表并勾选，也可手填群号。
6. 勾选“启用自动回复”并保存，核对弹窗中的对象、模型数据提交、旁听和全局记忆范围后确认。登录成功本身不等于开启回复。

概览显示四步进度与**已保存的运行范围**；编辑时明确显示未保存草稿。
“立即暂停回复”无需二次确认，取消后续段落与待处理请求。关闭窗口、清除上下文、覆盖全局记忆有明确提示。
开启自动回复、扩大或修改群范围、启用旁听/识图/搜索/本地工具/分段回复、更换模型或主人配置时，会展示对应影响。
重要设置由后端校验与待保存内容绑定的一次性确认凭证，过期或设置已变化需重新核对。

不需要填写 OneBot 地址、端口或 Token，不需要改 JSON 或另开 NapCat 管理窗口。
首次准备需要联网；应用安装包本身不包含 QQ 会话或 NapCat 的第三方运行时，后续复用已下载运行包。
自动部署目前支持 Windows x64。二维码不会上传到第三方二维码网站。
NapCat 属非官方 QQ 接入方式；界面明确提示使用专用机器人账号，平台可能限制账号登录或发言。

## 回复规则

| 设置 | 实际行为 |
| --- | --- |
| 群内 @ | 只识别 OneBot 的真实 at 消息段，文字伪造的 CQ 代码不能触发 |
| 关键词 | 与 @ 为“或”关系，不区分英文大小写；支持多个关键词 |
| 群聊范围 | 所有群 / 白名单 / 黑名单；私聊独立设置 |
| 白名单 | 只处理名单内群；**空名单不处理任何群聊** |
| 黑名单 | 排除名单内群，其他群仍须命中 @ / 关键词；空名单等同所有群 |
| 私聊回复 | 独立开关，关闭则不处理私聊 |
| 私聊带称呼 | 私聊没有群聊式 @，因此在文字前加昵称 |
| 回复 @ | 群聊可以真正 @ 请求者，默认关闭 |
| 监听上下文 | 默认关闭；开启后才收集未触发的旁听消息 |
| 上下文条数 | 0～100，含收到的消息和机器人答复，按群或私聊分别保存 |
| 回复间隔 | 同一会话冷却 1～300 秒；全局每分钟 1～60 条，每个分段各计一条 |

“记住刚才聊过的内容”默认开启：只保留已触发消息及答复，让关闭旁听后仍能连续聊天。
“也参考未触发的群聊”默认关闭：这是额外旁听开关，不再与正常的对话记忆混在一起。可单独关闭两者，完全不保留临时对话。
近期临时上下文仍在停止时清理；**已保存的自动记忆不会删除**。后续回复会读取本机记录继续聊天。
自动记忆默认开启、默认按群/私聊隔离，可在“自动记忆”页切到同一机器人账号的全局共享。
文件位于系统“文档/Cupbox/memory/qq-bot/机器人QQ/group/群号.json”或“private/对方QQ.json”；测试环境 CUPBOX_HOME 保持隔离覆盖。
自动保存已触发消息及实际发出的回复，保留每会话最近200条对话、最多500条用户原文片段，并按当前消息相关性召回最多8条；不额外调用模型总结，不把聊天原文冒充已核实事实。

“记忆管理 → 压缩摘要与 token 预算”默认开启，默认每轮约3000 token，可调2000～12000。预算分配给历史及摘要（60%）、相关记忆（20%）和明确公开的资料（20%）；这是启发式估算，不包含系统角色设定、当前请求、图片和本轮工具结果，不是提供方精确用量或费用上限。
旧对话用本机节选形成有发言者标识的摘要，优先选择偏好、约定与待办，最近6条尽量保留原文；单条超长时也会节选。摘要写入原会话JSON的`contextSummary`，只在原账号/会话读取，不随群间共享设置跨群传递，不额外请求模型。可在记录下展开查看摘要；压缩可能遗漏细节，原始记录仍按既有200条/500片段上限轮换，并非无限归档。
关闭压缩会恢复原有条数模式并保留已存摘要；关闭自动记忆不会读取摘要，永久删除某会话会连同该会话摘要删除。压缩前后历史估算可在运行日志查看，不记录摘要正文。
全局共享只共享相关记忆片段，近期对话仍按会话隔离，且机器人账号之间始终隔离。黑名单、白名单和私聊开关也约束跨群召回范围。
关闭自动记忆仅暂停使用和记录，重新开启可恢复；更换范围不迁移或删除原有记录。文件为本机明文，恢复回复时相关内容会发送给所选模型。
记忆页显示实际路径，支持查看、编辑笔记、打开目录、永久删除单个会话记录。删除有原生二次确认，并取消进行中的回复，防止旧结果重新写回。
“应用全局偏好与协作约定”仍是独立开关，不会被机器人自动记忆覆盖。
被白名单排除或命中黑名单的群不会收集上下文。升级时，旧的非空允许群号列表自动迁移为白名单。
消息正文与身份分开：内存记录保存独立 `sender.qq` / `sender.nickname`；提交模型的 user 正文不拼接 QQ 号。
OpenAI 兼容通道使用独立 `name: qq_号码`；Anthropic 使用独立的消息索引身份元数据，正文保持原样。
最多保留100个会话的上下文；消息去重表、队列、并行模型调用也有上限。
运行动态只显示连接、触发、字数和错误等元数据，不存聊天正文；托管 NapCat 的文件和控制台日志被关闭。
QQ 协议端本身仍可能维护它的账号缓存，区别于应用的模型上下文。
“测试已保存规则”只做本地规则匹配，不调用模型、不向 QQ 发消息。

## 分段式流式回复

“消息与节奏 → 像聊天一样发消息”可开启，默认关闭。每段目标字数 80～600、段间最小间隔 600～5000 毫秒，每次最多 2～6 段。
界面入口现在为“消息与节奏 → 像聊天一样发消息”。默认使用自然语意分段：短回复保持一条，长回复优先按完整句意，长句只在合适标点或空格处拆分，不强行截字。
代码块、编号列表和标题保持完整；链接、括号、引号内的内容不会从中间切开。原来的按字数方式可作为兼容选项选择。
首页提供使用当前草稿的本地节奏预览，经过同一分段规则，不调用模型、不向 QQ 发消息、不修改已保存设置。
“人格与能力”提供随口聊聊 / 认真聊聊 / 详细说明三种实际提示策略，聊天时减少固定开场、无意义总结与默认列点；工作模式继续强调任务核对。
纯文本 OpenAI 兼容 / Anthropic 接口使用 SSE，按完整句段或目标字数边生成边发送，只公开正文，忽略思考内容。
启用搜索或本地工具的流程、免费通道，以及返回普通 JSON 的兼容接口，在结果完成后分段，不广播工具中间输出。
首段按设置 @ 或加称呼；表情标记不会作为文本泄露，每轮最多一张。工具选图时先完成图片发送、取得结果，再分段接话；原触发规则附图仍在最后一段。
聊天最多1800字，工作最多5000字；最后一段接收剩余正文，目标字数不等于每段硬上限。
**已发送的段落无法自动撤回**。暂停、停止、清除上下文或修改设置会取消后续发送。
网络错误、接口截断或达到频率上限可能仅发出部分内容；运行动态会提示已发段数，不自动重试，以免重复发言。

## 模型、人格与能力

文本和视觉分别选择模型库中的连接，不另存一份模型密钥。
温度传给文本接口；已有的模型兼容层会对部分推理模型采用其自身采样策略。
思考深度选项依模型能力变化，使用实际接口参数。

聊天预设提供“温柔搭子”和“蓝色大肥鱼”风格，另可只用自定义设定。
鲸鱼娘预设是按机灵、简短、有主见等风格重新编写的提示词，没有把未经许可的 DSH 插件源码或长篇提示词复制进软件。
聊天模式不会获得本地文件工具。工作模式可以只做任务讨论，也可以由主人开启受限文件工具。

**联网搜索**默认关闭。开启后，普通支持工具调用的模型可按需调用 `web_search`，
实际检索 Bing 的公开 RSS 搜索结果；只请求固定 HTTPS 域名，不跟随重定向，不继承浏览器登录信息。来源被作为不可信参考内容，结果包含链接。
免费文本通道仅在消息明确包含“搜索 / 查一下 / 查找 / 联网”时执行一次检索，不假装支持 Agent。
搜索可用性取决于网络和公开搜索源，失败会产生运行动态，不伪造结果。

**图片识别**默认关闭。开启后，只读取触发消息最多两张图片，
按公网地址校验、DNS 固定、5MB/张、像素限制和位图签名检查后压缩，再发送给所选视觉模型。
关闭后不抓取图片，也不调用视觉模型。免费通道不能冒充视觉模型。

## 工作模式

先设置主人 QQ 号，再启用本地工具。只有主人消息、工作模式和本地工具开关同时满足时才开放工具。
每次文件操作，包括读取，必须在机器人窗口人工批准。确认框展示发起 QQ、来源群、目录、参数和可用的变更预览。

开放：分页读文件、文件信息、搜索、差异、写入、编辑、创建目录、补丁。
目录沿用主窗口工作文件夹；路径、敏感文件、预览令牌和冲突检查继续生效。
不向 QQ 开放 shell、终端、任意进程控制、剪贴板、删除或全局记忆写入工具。
模型和聊天内容不能替代本地批准。文件内容可能流向模型或 QQ，批准前请核对收件场景。
免费模型可在“人格与能力”开启“免费模型兼容工作流（实验性）”，首次启用确认第三方数据和执行风险；默认关闭。
兼容工作流使用严格 JSON 文本协议请求已有工具，不要求免费通道原生支持 function calling，不绕过关闭或封禁的通道。
只接收当前提供的工具名和对象参数，每次最多4轮；格式错误、未知工具、拒绝或工具错误时停止，不自动重试，不自动切换付费模型。
本地工具仍只在工作模式、主人身份和逐次本地批准后执行；读取内容也可能进入免费服务与 QQ 回复。原有路径、预览令牌与写入保护保留。

## 全局记忆

机器人使用与桌面工作台相同的全局偏好、协作记忆和相关全局事实；不召回其他项目专属事实。
“全局记忆”页可编辑共享的 `memory/user.md` 与 `memory/memory.md`，保存立即影响整个应用。
全局记忆开关默认开启，但机器人自动回复默认关闭；界面持续提示共享信息可能影响 QQ 公开回复。
可关闭此开关，使回复不加载全局记忆。群聊文本不会自动写入全局记忆，避免旁听污染长期设定。
不要在共享记忆中放密钥、密码或不愿公开的信息。

## 表情包

导入 PNG / JPEG / GIF / WebP，最多100张，单张最多8MB。新导入表情默认禁用。
必须填写含义，再允许使用。支持三种发送方式：

- **命中触发词发送（已有配置默认）**：由程序选择一个符合条件的表情，不再依赖模型准确输出 UUID。
- **关键词内由模型选图**：当前消息需命中关键词，再由模型选择符合含义的表情。
- **按含义智能选图（新导入编辑器推荐）**：无需关键词，由模型搜索素材含义并请求发送。

两种方式都检查：

- 图片仍在图库且含义完整；
- 表情总开关和该图片均已启用；
- 关键词模式下当前消息含配置的触发词；按含义模式无需命中；
- 会话表情冷却已结束。

每条回复最多一张；模型伪造 ID 或不满足条件的标记会被移除。
表情页持续显示**已保存的总开关**，每张图片有独立允许开关。只允许图片但没开总开关不会自动发送。
“本地检查条件”显示自动回复、登录、总开关、图片允许、含义、触发词及选择方式；不会调用模型或发消息。
扫码连接后，可以填写目标群号/私聊QQ，经过原生对象确认后发送一次真实测试图片；手动测试不依赖自动触发开关，成功后至少间隔5秒，不自动重发。
静态图解码并规范为 PNG（最长边1600像素），GIF 保留原动图；发送仍受8MB和像素限制。自定义表情通过标准 OneBot `image` 消息段的 Base64 文件发送，参考[OneBot 图片规范](https://github.com/botuniverse/onebot-11/blob/master/message/segment.md#图片)。
协议端拒绝会显示返回码和分类原因；未返回有效消息编号或超时视为**结果未确认**，请先在 QQ 核对，避免重复发送。返回消息编号也不代表已验证对方客户端显示。
QQ 回复使用结构化文本段，模型输出的 CQ 代码不会当作命令执行。
移出图库立即禁止后续使用；原始导入图片不受影响。

## 实时控制台

机器人窗口侧栏 → **控制台**。实时记录连接、触发/跳过原因、模型请求、工具请求、表情筛选、图片校验和 OneBot 发送结果。
支持级别/阶段筛选、搜索群号与返回码、自动滚动、暂停显示、复制和导出 JSONL。暂停只冻结显示，后台仍继续记录；新错误会在侧栏显示提示。
最多保留1000条内存日志，筛选视图显示最近500条；退出应用后不保留，需手动导出。清空日志不删除自动记忆。
默认不记录聊天正文、提示词、模型完整响应、工具参数或图片 Base64；只保留必要的时间、阶段、账号/会话标识、结果码和计数，并过滤密钥、认证头和 URL 查询参数。导出仍可能含群号或QQ号，分享前可自行检查。

## 数据与运行

机器人设置、表情副本和协议端保存在应用数据目录的 `qq-bot/` 下；
默认 `文档/Cupbox`，设置 `CUPBOX_HOME` 时为其下的 `.cupbox`。
模型密钥沿用原模型库；向 NapCat 子进程只传必要的系统变量与独立资料路径，不转发模型密钥。
OneBot 和 WebUI 只绑定 `127.0.0.1`，每次启动重建随机令牌；界面不暴露令牌。
WebSocket 定期检测状态并自动重连；离线、停止或设置改变会取消旧请求，防止迟到回复发出。
卸载应用继续保留账号资料和配置；若需清理，先停止机器人，再备份或移除数据目录中的 `qq-bot`。

- 新增 get_datetime、recall_memo、update_memo。记忆工具仅在自然聊天、自动记忆和偏好整理均开启时提供；每轮最多追加2条有当前用户原话证据的普通偏好，不接受任意文件/目标账号，不覆盖原始对话或权限。免费模型仍采用有界 JSON 协议，本地文件能力仍由原有独立批准控制。

- 旧记忆中的可疑指令或敏感内容不再召回到模型，原文件保留供本机审阅。网页、图片识别及批准读取的文件结果带不可信资料标识；疑似注入内容整体隔离。此类启发式检测可能误报，也不能识别所有编码、间接或多轮攻击。
- 私聊内容无论共享开关如何设置，都只在原私聊使用；全局模式只允许同一账号、已允许群之间共享。群白黑名单仍生效。
- QQ 公开资料改为单独的 qq-bot/public-memory.json，由本机界面明确填写；开启 globalMemory 只读取这份公开资料，不再自动读取应用私有 user.md、memory.md 或全局事实。原有应用私有记忆不删除、不改写，已有私有信息不会自动复制到公开资料。
- 自动偏好只能追加当前发言者原文中的普通偏好。摘要必须是证据的直接子串，不允许模型利用真实证据夹带另一条指令；拒绝敏感内容、权限要求、编码指令以及任意目标参数。一轮最多2条、每人每会话最多20条、每会话总计100条；满额拒绝新写入，不挤掉他人的事实。原文片段每人最多50条，总计500条，只轮换自己的片段。用户 QQ 由事件决定，不能由工具参数指定。
- QQ 不提供删除/覆盖记忆或改权限工具，原有遗忘、编辑、删除仍通过本机可信窗口执行。手工编辑/删除使旧的在途写入失效。攻略工具也拒绝额外分数或其他用户参数。
- 只执行本轮定义的工具；公开搜索词不能包含已识别的凭据或注入指令。文件工具保持主人、工作模式与逐次批准，阻止访问或覆盖应用记忆、配置与凭据目录。桌面 Agent 即使选完全控制，长期记忆新增/遗忘/覆盖仍需本机单次批准；只读查询不增加此项强制批准。
- QQ 回复完整返回并经过敏感信息检查后才分段发送，不提前发送未经检查的生成片段；密钥模式或已配置模型密钥命中时取消发送。这降低分段泄露风险，不能保证对任意编码形式的外泄都能识别。

保护始终开启，规则页显示边界说明，控制台增加“安全拦截”筛选。安全限制不代表模型完全可信：仍需核对本地文件批准，避免把秘密填入公开资料，并维护本机文件备份。测试只调用本地 HTTP/QQ 桩，不发送真实消息。

安全补充：桌面 Agent 的通用本机 run 命令也始终需要单次批准；工作台白名单命令在执行前仍需明确批准，避免借助脚本绕过记忆专用工具的检查。批准执行的本机代码仍有操作系统权限，需核对具体命令。项目/共享记忆写入同样强制批准。


## 插件中心（构建 1021 插件接口，版本1.0.3）

侧栏新增插件中心，首个内置示例为输出内容检测，默认停用。插件 API v1 为声明式 JSON，不执行外部脚本。可以导入文件夹、配置拦截词/脱敏词/长度限制、本机预览、启用/停用和移出外置插件。主对话最终文字与 QQ 最终文字共用规则；不覆盖媒体、工具回执或工作流预览。详见 [插件接口与示例](PLUGINS.md)。

## qq-bridge 功能融合（1023，版本仍为1.1.0）

### 设置入口整理

QQ窗口按任务分为「基础设置」「陪伴与素材」「高级与维护」，高级组默认折叠。原有设置键、保存格式和权限边界不变，只移动原有表单节点，没有复制第二套开关。

| 想做什么 | 入口 |
| --- | --- |
| 扫码、启动、暂停自动回复 | 连接与运行 |
| 群白黑名单、私聊名单、@与关键词触发 | 回复对象 |
| 连续接话、分段、语气长短、主动插话、上下文、定时提醒 | 聊天节奏 |
| 人格、名字、蓝色大肥鱼自由演绎、恋爱玩法、单群背景 | 角色设定 |
| 文本/视觉模型、温度、思考深度、联网、免费模型工作流 | 模型与能力 |
| 自动记忆、共享范围、QQ公开资料、置顶、词库 | 记忆管理 |
| 好感、心情、日记、作息、未完成事件 | 关系成长 |
| 图片图库、原生表情、语音素材 | 表情与语音 |
| 自主工具总开关、额度、主人QQ、本地文件批准 | 高级与维护 → 工具与权限 |
| 输出检测、日志、用量与估算费用 | 高级与维护下的对应页面 |

左栏功能搜索支持 Ctrl+K，可用“好感度”“白名单”“语音”“工具步骤”等词定位。结果显示分区路径，跳转后展开必要的折叠项并高亮目标；不会自动启用权限或改变任何设置。尚未满足的前置条件以可跳转的提示显示。

切页保留设置草稿，侧栏标出哪些页面有修改，底部统一显示数量并保存所有机器人设置；「放弃草稿」需同主题确认，只恢复机器人设置，不撤销已单独保存的素材、记忆或插件。非法参数在保存前定位到相应页面，显示同主题行内错误，不使用系统校验弹窗。词库/语音含义的未保存编辑也会保留并标记，保存成功后移除本条草稿标记。

溪语 AI 的好感、情绪、日记、未完成事件与记忆衰减适配，见 [QQ相处成长与适配边界](QQ-XIYU-COMPANION.md)。入口在原机器人窗口的「关系与心情」，共用现有关系存档。

### 自主聊天与日常互动补充

继续参考 qq-bridge 的工具自主会话和 Amadeus 的分批接话架构，在原有文件与界面上适配。未增加 SnowLuma 或复制许可证未明确的第三方实现；原有复用的 Markdown 清理保留 MIT 声明。

- 「会话工具」增加克制群友 / 熟人闲聊 / 活泼搭子三档草稿推荐。会开启自然聊天、旁听和消息工具；保存前仍显示对应风险，主动插话群、联网、音频与文件权限不随推荐开启。
- `followUpWindow` 为0～300秒，默认0。只有程序确认已向某人回复后才建立窗口，同群同一人无需再次 @ 即可继续；需要旁听与非零上下文。明确 @ 第三方、引用第三方、过期或停止后不会走这个接话规则，原有关键词规则仍独立生效。
- 自主工具轮数 `maxToolTurns` 为4～16，消息额度 `maxToolMessages` 为1～12，每条 `toolMessageChars` 为80～2000；默认6 / 4 / 600。实际自定义工具适配器支持16轮，免费通道仍最多4轮，整轮仍受超时、总发送限速、内容检测与停止取消约束。普通对话不因此放宽本机文件权限。
- 新增短句气泡模式 `bubbles` 与随字数变化的发送停顿 `typingDelay`。保留代码、列表、链接与成对引号，分段最多按原 `maxSegments`；停顿不低于配置间隔、最多5秒。源版鲸鱼娘仍按原行发送，自由演绎才使用自选模式。
- `qq_send_face` 支持7种原生表情；独立开关默认关闭，不必导入图片。计入实际已发送消息，最终回复不会重复转发；仍受总发送额度，图片/语音/戳一戳原有开关不变。
- `qq_ask_question` 可先发一个澄清问题，再等原发言者回答，最长60秒。其他群友不能冒充回答；等候前登记，避免接收时序造成重复排队。仅在旁听与非零上下文下提供。
- `qq_roll_dice` 使用本机加密随机源，1～10枚、2～1000面；`qq_random_choice` 从2～20个短选项抽签，不自动发送或授予额外权限。结果由模型按当前聊天风格表达。
- `qq_reminder` 可建立、列出、取消自己在当前会话的提醒。创建必须来自本轮明确的提醒要求，不接受主动唤醒自行创建。10秒～7天、每人每会话最多10个、全局最多50个待发，内容最多300字。默认关闭，开关及送达限制有风险说明。
- 提醒持久保存在原 `qq-bot/reminders.json`，最多保留150条非待发历史；不会写入人格或授权配置。软件运行、QQ在线且自动回复与提醒开启时约每3秒检查到期；核对当前登录账号、名单、私聊开关、内容插件及密钥保护。只发原会话并 @ 原请求者，不调用模型、不允许指定其他目标。逾期10分钟以上标过期，发送前持久标记 sending；失败为failed、崩溃留下sending均不自动重发，避免重复打扰。本机可查看并取消待发提醒；关闭/暂停保留文件，不是离线闹钟或紧急提醒服务。
- 人格页的「自由演绎」通过 `whaleFreedom` 显式开启，默认false，保留此前严格原版行为。开启后名字、性格、补充设定、语气、分段和恋爱玩法可由本机自定义，使用通用角色检查与表情工具，不再套用源版固定表达检查；人设副本也保存该选择。安全、身份真实性和本机权限边界仍由程序执行。

自动化测试覆盖接话对象与过期、未发送不建立窗口、16轮适配、额度溢出、真实随机、追问对象与等候去重、原版/自由演绎隔离、提醒持久化、账号与群隔离、离线暂停、过滤与不重复发送。界面测试覆盖草稿/保存、启用风险和取消提醒；未连接真实 QQ 或付费模型。
