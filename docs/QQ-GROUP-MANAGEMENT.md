# 群聊管理

入口：QQ机器人侧栏 → 群聊管理。总开关、检测规则、处罚动作、通知和手动管理均默认关闭。群管与自动聊天回复分别开关；已登录的当前QQ需要目标群的群主或管理员权限。使用 NapCat / OneBot 11 群管理接口，QQ官方机器人和其他平台不执行这些规则。

## 使用

1. 在“范围与分群”明确填写管理群号，设置豁免用户和可选黑名单。
2. 在“内容与刷屏”启用需要的检测，违禁词一行一条，支持含空格的短语。包含与整条匹配不执行正则表达式；统一全角、大小写并移除常见不可见分隔符。
3. 可先开“仅观察”查看命中记录，确认后关闭观察模式，按需打开撤回、警告、禁言等动作。
4. 点击底部“保存所有设置”。分群覆盖也需要保存后才生效；不会自动向管理名单添加群。

内容检测包括违禁词、黑名单、链接/分享卡片、图片、file消息段、长文字、批量提及和全体提及。频率规则按群、用户隔离，支持连续刷屏、重复消息与北京时间安静时段。链接域名白名单按域名边界匹配并允许子域名，不会抓取外链。分享卡片整体限制，不进行卡片内容识别。独立群文件上传通知不支持通过消息ID撤回，本规则只检查协议消息中的file段。

## 处罚与记录

开启撤回时，仅成功撤回才增加有效违规次数；未开启撤回时按命中累计。一个消息命中多项规则只计一次。达到禁言阈值后执行设定时长，再累计达到阈值才重新禁言；移出阈值单独开关，不永久拒绝加群。窗口到期的次数不再计算。

警告可使用 `{用户}`、`{原因}`、`{次数}`，同用户有独立冷却。欢迎/离群提示可使用 `{用户}`、`{群号}`。所有模板为本地固定文字，不请求AI。

群主、管理员、自身、主人名单和额外豁免名单始终免于处罚。处罚前通过接口核对身份，不依赖消息中的角色字段。只有明确管理的群执行，设置保存、停机、切换账号会取消尚未提交的任务。过期或未来异常时间的事件不处罚。每分钟最多30个动作，不自动重试结果未知的提交。

手动面板可禁言/解禁、移出、全员禁言/解除、按消息ID撤回。需要单独启用“本机手动管理”；观察模式禁止手动执行。撤回前校验消息属于目标群及发送者权限，不向群聊或AI开放管理工具。

本机文件：当前机器人账号工作区的 `moderation-log.json`（最近500条，仅原因与动作状态，无正文）和 `moderation-strikes.json`（分群、分用户计数）。页面每5秒刷新，支持群/用户筛选、指定用户清零。记录中“已确认”指协议接口成功返回；超时标为“结果未知”，不声称操作成功。

接口定义参考 [OneBot 11 公开 API](https://github.com/botuniverse/onebot-11/blob/master/api/public.md) 与 [通知事件](https://github.com/botuniverse/onebot-11/blob/master/event/notice.md)。
