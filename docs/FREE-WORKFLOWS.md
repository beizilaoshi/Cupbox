# 免费模型兼容工作流（1.0.3）

免费模型可以参与规划、串行/并行子任务、审阅和整合。在主窗口设置开启多模型工作，选择免费文本模型及相应流程；子项目工作模型和审阅模型列表也包含已开启、可用的免费模型。

“做一做”及工具面板的免费 Agent 使用实验性 JSON 兼容协议：模型通过文本请求已提供的工具，执行器校验后调用现有受保护入口，再把真实结果回填给模型。不会把自然语言或代码块直接当成命令，不表示服务原生支持工具。

工作流开始前显示第三方服务风险确认，取消后不提交本次模型请求。免费服务可能限流、停用、中断或返回不符合格式的内容；多个子任务会增加请求次数。不会继承付费 API Key，也不会自动切换付费模型。

免费 Agent 仅开放项目范围内的文件读取、信息、搜索、差异、写入、编辑、建目录与补丁。每次工具请求都有本地批准，即使主窗口设置完全控制也不能跳过。写入预览、确认令牌、路径、敏感文件和冲突保护照常执行；不开放 Shell、任意进程、删除或授权策略修改。

每个兼容 Agent 最多4轮工具请求。取消、未知工具、格式错误、批准拒绝和工具错误都会停止，不自动重试。已经完成的操作不会自动回滚，请核对实时工具记录并提前备份重要文件。

QQ 机器人另有默认关闭的免费兼容工作流开关，且本地文件能力仍要求工作模式、主人身份和逐次批准；搜索沿用固定公开搜索接口。

验证使用隔离数据及本机模拟免费 API，实际测试了工作流 HTTP 协议、真实文件读取、结果回填、风险取消零请求和付费密钥隔离。公共免费服务的当前可用性、配额和模型格式遵循度不保证。
