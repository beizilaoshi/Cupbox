# 本机渗透测试 Agent（1.0.3）

设置 → 权限与环境 → 本机渗透测试 Agent。**默认关闭，侧栏入口隐藏**。开启时必须通过应用内风险提示，取消不写入开启状态，也不会扫描。开启仅显示入口，不自动运行；每轮仍需输入端口并确认自己有权测试。

## 实际能力和复用来源

复用 MIT 项目 [baalexander/node-portscanner](https://github.com/baalexander/node-portscanner/tree/9a92dcce423da9bc16b4f3c621bacdf7dcc0bfc1) 的 `checkPortStatus` socket 生命周期逻辑，并复用 Cupbox 现有 `aiAgent` 调度，不引入任意命令执行器。上游原文、MIT许可证和改动说明随软件位于 `desktop/loopback/vendor/node-portscanner/`；固定提交及文件 SHA256 记录在 SOURCE.json。

- TCP 检查：只确认用户本轮选定的端口是否开放，开放不等于漏洞。
- HTTP 安全头：固定 `/` 的 HEAD 请求，提示 CSP/nosniff/框架策略缺失。需要结合用途、其他策略与实际服务复核。
- 可选配置暴露检查：对 `/.git/HEAD` 和 `/.env` 发送固定 GET 请求，仅返回疑似暴露结论，不返回正文或配置值。
- 固定流程不需要模型。可选“让本机模型自主规划”仅使用在模型管理中配置的 **OpenAI兼容、本机HTTP文本模型**，例如本地服务的 `http://127.0.0.1:端口/v1`。未配置时仍可使用固定流程。
- 进度和报告仅留在窗口/内存，复制报告是用户单独点击的本机剪贴板操作，不自动写入聊天、记忆或文件。

这是有界的本机检查入口，不包含漏洞利用、口令爆破、任意路径/参数模糊测试、命令、脚本或完整扫描器插件执行。

## 不能通过模型更改的边界

固定目标是 **127.0.0.1**（不是用户输入的易混淆缩写）。主机不作为工具参数。工具只接受整数端口和枚举路径，不提供URL、请求头、凭据、代理、任意方法或主机字段。

原始URL在解析前严格校验，拒绝 `127.0.01`、`127.1`、整数IP、八进制/十六进制IP、其他127网段、`localhost`、`::1`、`0.0.0.0`、公网/内网域名、内嵌凭据、查询串、片段和非HTTP协议。连接使用固定 IPv4 地址，无DNS解析、无环境代理、无重定向跟随，并核对实际对端地址。模型请求也使用独立的固定地址传输，不能回落到普通 fetch、云模型、免费通道或代理。

只提供 `loopback_ports` 和 `loopback_http` 两个专用工具，不继承普通聊天/QQ/工作台的文件、记忆、Shell、公开搜索或其他工具。用户输入和本地服务内容不能增加权限。模型工具调用的端口必须属于本轮已确认集合；未勾选额外暴露检查时，即使模型请求也不能访问两个附加路径。

每轮最多16个明确端口，不支持端口范围；最多48次检查连接。固定流程最多对8个开放端口做HTTP检查。模型最多4轮、单轮最多12个工具请求，模型侧总工具执行最多12次；TCP连接400ms超时、HTTP检查2秒超时，模型请求25秒超时，总任务90秒。检测正文最多读取16KiB，模型响应最多1MiB，请求正文最多2MiB。

任何重定向均拒绝，包括跳到另一个127.0.0.1端口；不会读取 Location 后再验证或发起第二跳。HTTP结果只保留端口、路径、状态、截断标记及规则结论，Cookie、环境变量值、Git文件正文和HTTP原始响应头不进入模型或报告。模型解读经过现有敏感输出检查与已开启的输出检测插件。

关闭、停止、关闭检查窗口或退出应用会取消在途任务，后续请求不再执行。通用 prefs:set 不能修改开关或确认版本，专用风险确认接口只接受主窗口本地操作。

## 仍需知道的影响

本功能直接连接本机服务，文件沙箱不会隔离本机服务。HEAD/GET与端口连接仍可能触发服务日志、限流或实现缺陷；已完成的请求无法撤回。只测试自己有权测试的服务。程序仅约束本模块发出的连接，不能控制被测本机服务内部如何处理请求，也不改变普通对话和更新检查原有的网络行为。

只支持HTTP；HTTPS、非HTTP服务或特殊鉴权服务可能无法检测。规则提示、模型建议和“未发现”都不构成安全认证。模型文字仅作参考，程序实测表才是检查证据。

测试只连接测试进程自己创建的127.0.0.1临时服务，覆盖地址变体、重定向、越权端口/路径、云模型拒绝、模型传输、关闭取消与真实设置交互，不扫描用户现有服务。

## 风险提示界面

开启确认与配置暴露探测确认均使用应用内弹窗，跟随深浅主题；默认聚焦取消，必须勾选了解影响才能继续，Esc 或两分钟未操作按取消处理。配置暴露探测每轮单独确认端口与两个固定 GET 路径。关闭窗口或刷新页面会取消未决确认。免费模型工作流、本地文件逐次批准、QQ 永久删除与真实发送、退出等操作也采用同一套提示样式。
