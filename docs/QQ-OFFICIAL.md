# QQ 官方机器人接入（Cupbox 1.1.1）

入口：**QQ 机器人 → 运行与账号 → 连接与运行 → QQ 接入方式**。

同一个 Cupbox 可以同时运行个人 QQ / NapCat 和 QQ 官方机器人。各账号工作区分别保存配置、凭证和记忆，仍遵守最多 8 套配置、4 个运行实例的限制。建议新建一个独立账号工作区配置官方机器人，避免反复切换同一份配置。

## 配置步骤

1. 在 [QQ 开放平台](https://q.qq.com/) 注册并创建机器人，取得 **AppID、AppSecret**。不要把 AppSecret 发到 QQ 聊天或写入角色提示词。
2. 在平台检查群聊与单聊权限、沙箱测试成员、出口 IP 白名单和发布状态。按平台当前提供的方式添加或测试机器人。
3. 在 Cupbox 当前账号工作区选择“QQ 官方机器人 · AppID / AppSecret”，填写两项凭证，点击“加密保存凭证”。
4. 点击底部“保存所有设置”，再配置文本模型、角色和回复范围。自动回复可以先保持关闭。
5. 点击“连接官方机器人”。本入口使用腾讯官方 Node.js SDK 的 WebSocket 方式，从本机向外连接，不需要个人 QQ 登录或安装 NapCat，也不需要在 Cupbox 配置公网回调。
6. 通道在线后，使用平台允许的测试成员单聊或群内 @；需要自动回复时再开启并保存。未通过鉴权、通道未就绪或没有权限时，不能把“已保存凭证”当作连接成功。

SDK 和平台能力可能调整；以 [QQ 官方接入文档](https://bot.q.qq.com/wiki/develop/api-v2/) 和 [腾讯官方 SDK](https://github.com/tencent-connect/qqbot-nodejs) 为准。

## 本版本支持范围

| 能力 | 官方通道状态 |
| --- | --- |
| 群聊 @ 与单聊文字回复 | 支持，走官方消息接口 |
| 收到图片、视觉识别 | 支持 HTTPS 图片；识别仍需开启视觉并配置模型 |
| 发送已注册表情图片 | 支持将现有图库校验后的图片上传；单次最多一张，可带文字 |
| 人设、聊天节奏、记忆、关系成长、睡眠固定回复 | 沿用现有流程，按官方 AppID 隔离记忆 |
| 联网、天气、知识库、当前会话里的安全聊天工具 | 沿用开关和权限；官方通道不提供合并转发读取与引用消息工具 |
| AI 日记 | 可按收到的聊天及明确指定的本机标识使用，默认关闭 |
| 频道、音频收发、戳戳、主页点赞、空间、点歌、提醒、主动推送、传话及本地文件工作模式 | 本轮未接入，相关开关在官方模式下停用；个人 QQ 模式仍保留原能力 |

这里列的是 **Cupbox 当前适配器** 的能力，不代表官方平台完全不具备其他 API。切换到官方方式保存时，不支持的开关会关闭；切回 NapCat 后如需使用请重新设置。不同接入方式的功能不能直接等同。

回复绑定实际收到的用户或群和本轮消息 ID。应用对回复上下文设置四分钟上限，超时不尝试主动推送；平台实际允许窗口与次数以接口返回为准。发送失败或结果不确定不自动重发，避免重复回复。

## OpenID 与名单

官方平台给出的是 **OpenID，不是真实 QQ 号或群号**。Cupbox 给每个用户和群生成稳定的 15 位本机标识，以兼容现有关系、白名单和记忆管理。

在接入卡片展开“官方会话标识与名单填写”，点击“刷新收到过的用户与群”，可在本机查看 OpenID 对应的本机标识。官方模式下，回复名单、主人、用户档案和日记名单应填写本机标识。不能填个人 QQ 号并期待平台将它识别为同一用户。

需要先收集标识时，保持自动回复暂停，连接后让沙箱成员发一条私聊或群内 @，然后刷新标识。标识记录容量为每 AppID 1 万条用户与群；消息标识只做有界内存映射，不逐条落盘。

## 本地保存与隔离

- AppSecret 通过 Electron `safeStorage` 调用系统加密，保存在当前账号数据目录 `qq-bot/official-credentials.json`，不会出现在普通设置、状态 IPC、诊断、提示词或模型配置中。界面保存后清空密钥输入框；需要更换密钥时重新输入。
- 系统加密不可用时拒绝保存。凭证文件不能当作跨电脑的通用登录凭证；更换系统用户或机器后可能需要重新填写。
- 用户与群的本机映射保存到 `qq-bot/official-ids-<AppID>.json`，包含 OpenID，请作为本地用户资料管理。
- 官方记忆位于原 QQ 记忆根目录的 `official/<AppID>` 子目录，与个人 QQ 记忆分开；不同账号工作区、不同 AppID 分开。
- 修改接入方式或凭证前先停止机器人。停止会断开连接、取消待处理回复，已提交给平台的消息无法因此撤回。

## 常见问题

- **保存成功但未在线**：保存只表示本机加密写入成功；还需要连接及平台鉴权。
- **鉴权或启动失败**：核对 AppID / AppSecret、平台状态、出口 IP 白名单和网络。查看“运行日志 → 连接与回复诊断”；不展示原始密钥或接口完整报文。
- **在线但不回复**：检查自动回复、私聊开关、回复白名单、群内 @、睡眠时段、模型和平台沙箱成员范围。
- **文字或图片发送失败**：检查平台权限、消息配额、图片限制和消息 URL 白名单。不要在结果未知时立即重复发送。
- **找不到个人 QQ 的好友、群列表**：本官方适配器不读取个人账号联系人；名单使用实际收到事件的 OpenID 本机映射。

## 开发与验证

新增运行依赖：腾讯 `@tencent-connect/qqbot-nodejs@1.0.5`，保留该依赖的 MIT 许可证。

`test/qq-official.test.ts` 覆盖官方能力限制、凭证接口、映射持久化、来源路由、图片上传桥接、过期回复、发送失败不重试、生命周期、SDK 的实际本机 HTTP 请求格式、原有聊天引擎及记忆隔离。

`desktop/verify-qq-official.mjs` 用独立测试目录验证实际打包目录中的 SDK 加载、Windows 系统加密、配置保存、密钥不回填、界面布局和重载。只用虚构凭证，**没有连接真实 QQ 官方服务或发送真实 QQ 消息**。
