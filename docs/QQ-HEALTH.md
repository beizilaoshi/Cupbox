# 运行体检与互刷保护（Cupbox 1.1.1）

入口：QQ机器人 → 系统管理 → 运行体检。测试构建显示 `1026 体检与互刷保护`。

## 互刷刹车

默认开启，可在面板关闭。个人QQ模式自动识别同一 Cupbox 里同时运行的机器人QQ号，忽略彼此的入站消息，不请求模型，不写聊天记忆。其他软件运行的机器人，可填写“其他机器人QQ号”。不同平台的本机映射标识不会当作真实QQ号交叉匹配。

对未登记的用户，如果90秒内连续3轮出现相同问答，第4轮暂停该账号、群或私聊、该用户组合的自动回复120秒。其他用户与群继续工作。只有实际发送成功的文字回复计入轮次，分段回复算同一轮；变换话题、未发送成功、只有图片的消息不靠此规则判为重复问答。对已识别机器人则直接拦截，不等待重复轮次。

冷却自动恢复，也可在面板手动解除。该规则是明确、可检查的循环检测，不声称能识别所有外部机器人或所有变体对话。

## 持续体检

启动账号后每30秒检查本机状态，不主动请求外部模型或向联系人发测试消息。体检页打开时每15秒刷新详细报告。

- 超过60秒连接未就绪，提示检查登录或平台凭证。
- 最近5分钟内，模型或发送连续至少3次失败，提示检查模型额度、网络或协议端。对应成功记录清除连续失败状态。
- 排队达到20条、诊断写入失败、互刷会话冷却时提醒。
- 告警只在新出现和恢复时写脱敏日志，主页展示提醒，报告可以复制。
- 结束账号运行时停止检查定时器；未开启的可选功能标为待配置，不当作运行故障。
