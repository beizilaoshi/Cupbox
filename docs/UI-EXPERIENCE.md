# 界面与交互统一调整

主工作台、设置15页、QQ机器人28页共用 `desktop/ui/experience.css` 与 `experience.js`。保留原有主题颜色、插画、后台功能和配置保存机制。

- 统一标题、表单字号、行高、卡片留白、控件高度和窄窗口布局。用户档案的数值条与两侧独立滚动继续使用专用布局。
- 设置标题区和QQ面包屑旁增加“紧凑视图”“收起说明”，只在本机浏览器存储界面偏好，不改机器人设置。警告与风险面板不随补充说明收起。
- 复杂选项基于已有说明、专门解释和数值范围显示问号。悬浮、键盘聚焦、点击均可阅读；点击问号不会触发表单修改。提示位于独立浮层，不受卡片滚动裁切；Escape先关闭提示，不关闭整个设置页。
- 中文混合记忆、共享范围、语音、短视频、表情模式、群管、模型API、工作流和关系数值都有针对性的说明。动态生成的字段通过DOM观察器补充，不读取密码或输入值来生成提示。
- 按页面记忆滚动位置；QQ导航不再强行关闭其他分组。长页面的卡片目录按需展开，分类标签横向滚动，避免挤成多行。页面下部可一键回顶部。
- QQ设置支持Ctrl+S，继续调用原有校验、风险确认和真实保存流程。无设置草稿时提示使用素材、笔记或档案自身的保存按钮，不误保存其他内容。

验证：`desktop/verify-experience-redesign.mjs` 检查提示、键盘、点击不改值、界面偏好、位置恢复、导航和Ctrl+S真实IPC保存；`desktop/verify-ui-consistency.mjs` 检查180个窗口/主题/页面组合；用户档案、欢迎欢送和记忆召回的独立界面测试继续覆盖保存与滚动。全部使用隔离配置目录和隐藏Electron窗口，不重启用户程序、不连接实际QQ。
