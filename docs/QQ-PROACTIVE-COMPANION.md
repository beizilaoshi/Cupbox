# QQ 主动陪伴与后台日记（1.1.1）

在 QQ 工作台的「主动陪伴」设置。所有新增功能默认关闭，各自开启并通过底部「保存所有设置」生效。不需要安装包更新，测试版目录中的程序已同步。

## 主动私聊

填写「可主动私聊的用户」QQ 号，选择空闲开场、早安、晚安、催睡、分享角色日常。只有已登录且消息连接在线、自动回复开启、聊天模式下才会向这些用户发送；私聊总开关、私聊范围、黑名单仍优先。名单最多20人，不会自动扩展为所有好友。

- 默认早安08:00、晚安21:00、催睡23:00、日常15:00（北京时间），时间可自定义。定时消息只在设定时间后15分钟内尝试，错过不集中补发。
- 默认23:30～07:30安静；起止时间相同表示全天安静。空闲开场默认只在09:00～21:00且已安静120分钟后发生，需要最近两天有该用户自己的私聊记录，每天最多一次。
- 每人每天默认最多4次主动尝试，至少间隔60分钟；可设置1～8次、15～1440分钟。失败、跳过也消耗本轮尝试，避免反复请求与刷屏。
- 催睡默认仅对最近一小时发过言的人发送，避免打扰已睡的人。多个功能时间冲突时，先匹配的问候优先，受统一间隔限制。
- 日常分享遵循当前角色口吻，分享想法与兴趣，不虚构真实外出、身体经历或线下见面。
- 用户私聊「不要主动找我」「不要打扰」「暂停主动」可以暂停所有主动消息，包括群聊趣事；「恢复主动」可恢复。本机也可在后台状态中恢复。暂停状态按机器人账号与用户隔离，退出后保留。

按机器人账号、日期、功能与接收者保存尝试状态，重启不重复发送。未知送达状态不重发。停止机器人、修改设置或插件会取消正在准备的主动消息；已经提交的消息不能撤回。所有自动私聊经过现有输出检测和全局发送限速。

## 向主人告状、分享群聊趣事

独立填写接收者与允许分享的群，默认20:30汇总。只从指定且仍在回复范围内的群收集，允许收集未 @ 机器人的文字，不依赖普通「旁听」开关。请让相关群成员知情。

每个接收者每天最多一条；至少有三段允许使用的群聊素材才调用模型，没有趣事可保持安静。模型只接收选中群的文字，不会夹带私聊，也不会把不同机器人账号的材料混合。会话和发言者在模型材料中使用代号，长数字会省略，并提示不要传播联系方式、敏感私事或把玩笑当作事实。

这里的「主人」只是接收者，不会加入本地工具权限名单。接收者也须符合私聊范围，可主动暂停接收。

## 后台 AI 日记

默认关闭。单独选择允许作为日记素材的群号和私聊用户，可以只选其中一种。默认23:15开始写当天日记，模型可跟随聊天模型或单独选择文本模型。开启后只积累新收到的文字，不追溯导入历史聊天。自动回复关闭时不再采集，但可用当天已允许的材料写作；QQ 离线后也可写本地日记。

原片段按账号、来源、日期标记，最多600条；仅使用近两天，运行时定期及重启时清理超期片段。日记只用今天、当前仍在允许范围内的素材。无素材时不调用模型。截图、图片、语音不会自动转写为日记内容。

每个账号每天一份 Markdown，保存在 `<Cupbox本机数据目录>/qq-bot/diary/<机器人QQ号>/YYYY-MM-DD.md`。工作台可阅读、打开文件夹、手动写今天日记。已经写好的日记不覆盖、不重复扣模型调用；失败后可手动重试。日记长期保留，不自动发送给主人、群聊或私聊。

应用需要运行才能调度；退出期间不后台唤醒电脑。日记时间已过，当天再次打开应用后可用已有素材补写当天日记，不补写前几天。模型只用于写文字，不获得网页、本地文件或 QQ 发送工具；请求计入现有模型用量。

## 验证范围

自动测试覆盖时间、名单、每日限额、发送间隔、暂停/恢复、账号与会话隔离、停止取消、未知送达不重试，以及本地日记写入与去重。实际测试程序通过本地模拟模型接口验证配置保存、模型调用、Markdown 存盘与阅读、最小窗口宽度和页面错误。未用真实 QQ 账号向联系人发送测试消息。
