# 睡眠与固定回复

入口：QQ 机器人 → 用户与陪伴 → 关系成长 → 睡眠与固定回复。

功能默认关闭，独立于相处成长。开启后按北京时间使用「休息时间」至「起床时间」，默认23:00至次日07:00，支持跨午夜；两者不能相同。作息同时用于既有的角色日常背景。

睡眠期间，原本符合私聊、群内 @、引用机器人、关键词、戳戳规则的请求直接使用本地固定文字，不调用回复模型、视觉、表情选择或语音生成，也不推进关系存档。默认回复为 `{model}睡着了，明天再找吧。`，其中 `{model}` 来自当前选择模型的本地显示名；没有可用名称时使用「AI」。

可以自行编辑回复，最长500字。`{wake}` 会替换为起床时间，例如 `07:00`；也可不使用任何占位符，直接填写固定文字。界面实时本地预览，不为预览调用模型。

已有自动回复总开关、白黑名单、群触发规则、输出检测、去重和发送限速继续生效。群内无关闲聊不发送睡眠提示；主动插话及后台主动私聊在睡眠时暂停。独立开启的后台日记仍按其设置运行。

到达起床时间后自动恢复正常回复，无需重启或切换页面。睡眠时收到但排队或读取引用信息后才处理的消息仍使用固定回复。发送失败不会回退到 AI 或自动重发。
