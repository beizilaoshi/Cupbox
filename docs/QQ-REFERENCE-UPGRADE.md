# 分享版参考项目的实用能力整合

参考用户提供的《QQ小号机器人 分享版 v0.62.1》设计，使用 Cupbox 原有 JavaScript 存储、IPC、运行体检重新实现，没有执行外部源码、安装脚本或重启脚本。

## 本地原话整理

入口：QQ 机器人 → 自动记忆 → 查看与整理 → 从原话建立偏好档案。

- “从已有原话预览”读取选中账号、会话最近最多 200 条对话，最多生成 100 个候选；不请求模型，也不写入文件。
- 仅接受安全的本人明确偏好与称呼原句，例如“我喜欢乌龙茶”“我不喜欢咖啡”“叫我小杯”。排除机器人回复、转述、引号内容、疑问及疑似注入、凭证。规则较保守，不代表能理解所有自然语言。
- 预览显示用户、原话、时间、来源标识、新增与确认数量；应用只新增或确认，不删除旧记忆。
- 预览绑定数据版本、账号、会话、记忆目录及命名空间版本，5 分钟过期。期间聊天变化或删除档案后必须重新预览，避免恢复已删除的数据。
- 自动整理默认关闭；开启并保存后只处理新保存的对话，与模型写入工具独立。原话整理免费、离线；后续正常聊天仍会把召回的记忆提交给已选择的模型。
- 相同来源重放不重复计数，新的相同偏好累计确认；新旧相反偏好分别保留，旧消息整理不会伪装成最新表态。
- 不改变现有会话共享范围、黑白名单或机器人账号隔离；新增数据继续保存到现有本机 JSON 记忆文件，兼容旧记录。

## 磁盘告警

入口：QQ 机器人 → 运行体检。检查数据目录实际所在磁盘，而不是固定系统盘。目录尚未创建时向父目录查找所在磁盘。

运行时每 30 秒检查；手动体检立即检查。85% 起提醒，92% 起严重提醒，跨级与恢复会记录脱敏日志。显示磁盘余量，不展示本机目录或错误原文。查询失败单独提示，不把未知余量当作充足。不会自动删文件、停止核心存档或清理用户数据。

## 消息通道重连退避

OneBot 连续断开后依次等待 3、6、12、24、48、60 秒，之后上限 60 秒。仅收到在线心跳或状态查询确认在线后重置间隔；单纯打开 WebSocket 不重置。停止机器人立即取消重连，也能处理 WebSocket 构造失败。

仅重新连接当前消息通道，不重启 QQ、不影响其他实例、不绕过平台检测，也不重发结果未知的消息。

## 本次未接入
