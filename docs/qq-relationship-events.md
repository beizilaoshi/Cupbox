# 情绪低谷与关系事件

在 QQ 机器人「用户与陪伴 → 关系成长」中配置。

## 情绪低谷期

先开启相处成长，再展开「情绪低谷期 · 角色生理周期」。功能默认关闭；开启时可设置首次开始日期、周期（14～60天）与持续时间（1～14天，短于周期）。默认28天一周期、持续5天，按北京时间计算。

低谷是机器人自己的虚构角色背景，会影响疲惫感、敏感程度和说话节奏，不自动扣好感或信任，不制造负面记忆或分手。结束后自然恢复。当前阶段可在「用户与机器人」的本人档案中查看。

## 分手与复合

「AI 判断分手与复合事件」默认开启，但只有恋爱玩法允许的成年角色关系才生效；未交往的对象不能被记录为前任。

好感为负时优先克制、冷淡和保持距离，不自动分手。AI 综合好感、信任、未修复矛盾和当前对话，通过关系事件工具决定是否结束关系，并引用本轮原话、记录判断理由。单纯离线、沉默或进入低谷期不会自动触发分手。

分手后取消恋人确认、保留既有记忆与数值，后续不使用恋人称呼，也不主动打扰。复合需要本人明确意愿及修复后的好感、信任、熟悉度和共同经历，不能一句道歉立即恢复热恋。

事件只能在本轮发送消息之前决定，实际回复成功发送后才保存；发送失败、内容被拦截或选择跳过不会写入。资料按账号、会话、用户、角色、场景隔离，本地保留最近30条关系事件。「用户与机器人 → 你们的相处 → 变化依据与心情」可查看原话、理由和时间。

编辑其他档案字段不会抹掉分手状态；本机手动重新确认关系可以覆盖当前状态，历史事件仍保留。
