# 设置页布局

设置默认打开「常用设置」，将模型、外观、桌宠、权限与工具作为六个快捷入口。左侧按「日常使用」「任务与工具」「更多设置」分组；高级导航默认收起，外部入口直达高级页时自动展开对应分类。

- 查找设置按页面名称和用途关键词过滤导航，不搜索密钥或用户配置值。
- 支持上下方向键、Home/End 切换可见页面，选中导航与页面标题关联。
- 页面切换回到顶部；在同一设置窗口中往返页面不会重新填入 API 配置、覆盖未保存的输入。关闭后再次打开时重新载入配置。
- 桌宠默认 140px（60–280px），常用开关、大小与衣橱直接显示；漫游、气泡、轻柔动效、位置恢复及动作库按需展开。
- 专项能力和安全提示保留：权限与运行仍有常用入口，工作流和第三方免费模型的风险提示不折叠进说明；开启危险能力仍走原确认流程。
- 版本保持 1.1.0，本轮修改源码，不修改正式安装包。

验证：`desktop/verify-settings-layout.mjs`，覆盖全部十三个页面、设置搜索、空结果提示、快捷入口、键盘导航、草稿保留、高级深链接、桌宠折叠区，以及深浅主题与最小窗口。截图保存于 output/settings-redesign-review。
