# QQ 互动玩法

入口：QQ 机器人 → 内容与日程 → 互动玩法。总开关默认关闭；可分别选择签到、运势、骰子、帮我选、投票。新增猜数字、成语接龙、倒计时、群内报名，四项新开关默认关闭，保存后生效。

群聊默认需要真实 @ 机器人，私聊无需 @。可关闭群聊 @ 要求、自定义指令前缀（默认 `/`）、每人每会话冷却和新投票时长。机器人必须在线并开启自动回复；仍遵守群白黑名单、私聊范围、睡眠时段、互刷保护及全局发送限速。不需要自主聊天工具、不调用 AI，也不会主动发消息。

| 指令 | 功能 |
| --- | --- |
| `/玩法帮助` | 查看当前已启用玩法及指令 |
| `/签到` | 北京时间每天一次，奖励5～15积分，记录连续及累计天数 |
| `/积分` | 本会话的个人积分 |
| `/签到榜` | 本会话积分前十名 |
| `/今日运势` | 当天固定的娱乐运势、幸运色与小建议 |
| `/掷骰 2d6` | 本机真实随机，最多10枚，每枚2～1000面 |
| `/帮我选 米饭 \| 面条` | 2～20个不同候选随机选择 |
| `/发起投票 午饭 \| 米饭 \| 面条` | 每群同时一个投票，2～8个不同选项 |
| `/投票 1` | 每人一票，可再次投票修改 |
| `/查看投票` | 查询票数；到期后显示最终结果 |
| `/结束投票` | 发起人、群主、管理员或机器人主人提前结束 |

签到和投票保存在当前账号工作区 `qq-bot/play-data.json`，按机器人账号和会话隔离，不随聊天记忆共享。运势按账号、用户和北京时间日期固定；同一用户跨会话不重新抽取。签到榜显示昵称、积分和天数，投票只公开计数。积分独立于好感和信任。

最多保存5000份签到档案、200个会话的最近投票和最近24小时内1000个指令事件编号；同一投票最多2000人。到期不会主动通知，只在下次查询/参与时结算。发出结果超时或未知时不自动重试；指令事件编号先在本机登记，重连重放不会重复执行。保存设置或停止机器人会取消待发结果。

参考玩法设计，使用 Cupbox 原有协议和设置流程重新实现，未安装外部 Python 插件或复制其代码/美术素材：

- [nonebot-plugin-fortune](https://github.com/Siornya/nonebot-plugin-fortune)：每日运势。
- [nonebot_plugin_cloudsign](https://github.com/Monarchdos/nonebot_plugin_cloudsign)：签到积分。
- [nonebot_plugin_cocdicer](https://github.com/abrahum/nonebot_plugin_cocdicer)：骰子互动。

验证：`npx vitest run test/qq-play.test.ts`；`desktop/verify-qq-play.mjs` 使用隔离 Electron 用户目录测试实际设置页面和 IPC，不连接真实 QQ、不向群发消息。

扩展指令（默认前缀 `/`，群内默认需 @）：

| 指令 | 功能 |
| --- | --- |
| `/猜数字 100` | 开启1～100的猜数游戏，上限可设10～1000 |
| `/猜 50` | 提示大了/小了；所有人共用次数，猜中或次数耗尽结束 |
| `/猜数字状态`、`/结束猜数字` | 查询进度或提前结束 |
| `/成语接龙 一心一意` | 开始本机词库接龙，不填则随机选有后续的词 |
| `/接龙 意气风发` | 按汉字首尾连接，不支持同音，不允许重复 |
| `/接龙提示`、`/接龙状态`、`/结束接龙` | 提示最多5个候选、查询、提前结束 |
| `/添加倒计时 活动 \| 2026-12-05 18:00` | 保存北京时间的未来日期；不主动提醒 |
| `/倒计时`、`/倒计时 活动`、`/删除倒计时 活动` | 查询全部、按完整名称查询、删除 |
| `/发起报名 周末开黑 \| 5` | 每群同时一个报名活动，人数2～1000，省略人数默认20 |
| `/报名`、`/退出报名`、`/报名名单`、`/结束报名` | 自己参加/退出、查名单、提前结束 |

新小游戏和报名默认30分钟有效，可设5～1440分钟；猜数字默认20次机会，可设5～100次。结束权限属于发起人、群主/管理员和机器人主人；倒计时删除使用相同权限。修改时长只影响新活动。成语接龙使用内置小词库，可在设置中添加四字成语；输入仅按格式校验，不联网核实释义。没有未用后续词时结束并说明词库限制。

倒计时每会话最多10个，标题唯一，时间必须有效且在未来十年内；过期仍可查询“已过去”，不会自动发消息。报名公开昵称（前20人及总人数），不能代替别人报名/退名。四种扩展各最多保存200个会话记录，仍使用 `play-data.json`，旧版文件自动补充字段，原签到和投票不丢失。
