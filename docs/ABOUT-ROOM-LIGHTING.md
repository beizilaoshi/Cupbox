# 关于房间光照修正

房间与工作、用餐、睡觉插画已经包含日光或夜灯，移除原来覆盖整幅画面的重复蓝色、橙色滤镜，改用轻微的定向时段色调。角色保留原始明暗，通过乘色环境光和滤色台灯补光匹配房间；独立 alpha 遮罩保持轮廓，避免把光画到角色外侧或拉扯五官。

窗光来自左上方，台灯位于房间坐标 (175,113)。补光按世界坐标衰减，走近台灯时受暖光影响更明显，离开后减弱。落地接触阴影及投影根据主要光源方向绘制。台灯关闭局部压暗灯罩并停止角色暖光补光，不改变远处墙壁。其他画在背景里的固定装饰灯保留。

该实现是二维插画局部调光，不改变之前已经移除形变的动作模型。版本维持 1.1.1，源文件及运行目录已同步。

验证：`desktop/verify-about-room-lighting.mjs`。在实际 Electron 应用的隔离配置中，检查六个时段、开关灯对附近角色和实际灯位的亮度影响、远处墙壁保持一致、三个固定活动场景以及无形变和无渲染错误。截图输出 `output/about-room-lighting-review/`。
