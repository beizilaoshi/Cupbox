# Agent 预设与插件中心

主设置新增「插件中心」，保留原工具开关并归入「本地工具」，不再把普通工具列表当作全部插件功能。会话插件采用搜索、预设选择、双列卡片和同主题开关；本机扩展接入现有输出检测 PluginHost，与 QQ 共用实际规则。

## 自定义预设与风险

- 标准、代码、渗透测试、三月七与创造预设均展示风险标签。选择代码/渗透/游戏自动化前显示软件同风格的风险确认，取消不修改选择。
- 可新增、编辑、删除最多20个自定义预设，名称40字、说明240字、指令12000字，保存至用户数据目录 `desktop.json` 的 `customAgentPresets`，不执行指令文本或导入脚本。
- 自定义预设必须继承现有基础模式；渗透/三月七的只读工具限制和专用启动确认不会因为自定义指令、角色插件关闭而消失。自定义提示词仍位于原有系统安全规则之下。
- 删除正在选用的自定义预设时回到其基础模式，而非放宽到标准模式，并清除该自定义预设的孤立插件开关；不删除聊天、记忆或项目文件。

## 会话插件

角色设定、时间感知、工作区文件、终端/PowerShell、联网/HTTP、桌面视觉与操控分别可按预设开关，状态保存在 `agentPluginStates`。

工具组开关会同时过滤模型请求中的工具定义与执行入口。关闭角色插件只移除预设工作方式，保留系统规则、固定127.0.0.1边界与基础模式的硬限制；联网插件不会误停本地文件搜索。当前任务使用启动时的配置。开启插件不等于授予工具、批准或桌面权限，原有工作目录、沙箱、写入预览、命令批准和窗口授权仍然有效。

## 本机扩展

可在主设置导入现有 API v1 声明式输出检测插件、编辑规则、本机测试、启停和移出登记。插件仅支持 `manifest.json`、`rules.json`，默认停用，不执行附带脚本。测试不会调用模型或发 QQ。启用/修改生效规则需风险确认；修改会取消 QQ 待发回复，保留持久记忆。插件文件异常时可停用以解除其最终文字拦截。

与已有接口一样，只过滤主对话与 QQ 的最终文字，不扫描图像/视频、工具回执或已流出的工作流进度，不能撤销已经执行的工具。核心安全检查始终启用。
