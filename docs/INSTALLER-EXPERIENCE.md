# 安装与卸载体验（1.1.0）

卸载的确认、执行和完成页采用统一的紧凑双栏布局：左侧筑梦喵玻璃画框，右侧步骤指示、操作内容及数据保留卡。卸载执行页隐藏原生表单的冗余面板和不可用的取消按钮，用圆角渐变进度条显示引擎原生进度；百分比直接读取原生进度控件，不按时间模拟。控件上下留白并校验边界。日志中的 `CUPBOX_UNINSTALL_LAYOUT` 记录实际控件边界，`CUPBOX_UNINSTALL_PROGRESS` 记录真实进度变化。完成时停用进度视图，避免访问已释放的进度窗口。

底部操作栏单独占用空间，与向导内容区互不覆盖。首次进入页面后按最终缩放尺寸计算底栏，保留原页面高度并增加窗口底部空间；按钮高度 42 个缩放单位，上下留白至少 16。后续每页复核布局，步骤提示与按钮对齐。日志中的 `CUPBOX_FOOTER` 记录各页面内容边界、底栏边界及按钮尺寸，异常布局会阻止继续操作。

2026-10-24 第二轮视觉重制：欢迎页使用独立圆角功能卡，侧栏采用筑梦喵与半透明画框；主次按钮使用高分辨率蓝紫渐变和轻盈描边，悬停、键盘聚焦以 4 步连续渐变反馈。保留原生安装引擎与键盘快捷键，自绘按钮转发已有操作，不绕过安装或卸载确认。退出与卸载的数据说明改为独立盾牌卡。所有交互按钮保留可访问名称，说明文字保留可访问文本；定时器在退出时释放，临时弹窗控件注销后再销毁。

安装器界面资源优先排列在压缩包中，启动引导不必先解压完整的应用载荷。卸载器在移除应用前缓存自身 UI 图片，完成卡不依赖已被移除的文件。

安装包：`release/Cupbox-Setup-1.1.0-x64.exe`。离线安装，不需要管理员权限；新样式在使用此安装包安装或升级后生效，旧卸载器需要随安装升级。

- 欢迎页沿用应用的樱花场景、蓝紫色与筑梦喵原画。三个键盘可操作的功能按钮切换插画与说明，点击插画也能切换。
- 安装路径、快捷方式、安装前确认按步骤展示；数据目录明确与程序目录区分。检测到目标已有程序时，安装按钮显示“更新并保留数据”。
- 进度百分比来自实际安装回调，无假倒计时。取消安装时出现同风格确认卡，默认继续安装。
- 卸载先显示图文确认卡，默认“先留下来”，明确只移除安装器登记的程序文件与快捷方式；不提供删除用户数据的勾选项。数据目录存在时可点击查看。
- 卸载进度和完成页沿用相同画风。完成页不承诺被占用文件立即删除，提示重启可能完成清理。系统错误或文件占用等操作系统级提示仍由安装引擎处理。
- 数据默认位于系统“文档/Cupbox”（支持系统文档重定向）；设置 `CUPBOX_HOME` 时显示该目录下的 `.cupbox`。不会扫描或上传数据。
- 普通双击卸载时，启动本地 `/SILENT /SUPPRESSMSGBOXES /NORESTART /CUPBOXUI=1` 工作进程，由它显示应用风格确认、进度及完成卡，避免系统默认确认重复出现。显式 `/SILENT` 或 `/VERYSILENT` 卸载仍不显示自定义确认，保持自动部署语义。
- 图像由 `desktop/installer/build-assets.mjs` 从既有项目插画与透明吉祥物素材合成；不新增外部下载和第三方执行代码。脚本使用 Inno Setup 原生支持的控件和事件。

验证：`desktop/installer/verify.ps1` 使用独立测试 AppId、工作区下的中文带空格安装目录和隔离数据，检查离线安装、同版本覆盖升级、实际应用加载与卸载后的数据保留。测试构建独有 `/CUPBOXREVIEW=complete` 可预览完成卡但不执行卸载，正式构建不包含此入口。
