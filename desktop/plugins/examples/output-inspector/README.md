# 输出内容检测插件 · API v1

随软件提供，默认关闭。打开 QQ 工作台 → 插件中心，编辑词表后保存并启用。

`[禁止发送]` 是默认示例拦截词。可在测试框输入“这是一条[禁止发送]的测试消息”，测试只在本机运行，不调用模型、不发送消息、不存为聊天记忆。

`blockWords` 命中任意字面文本时取消整条最终文字；`maskWords` 命中时替换成 `replacement`，`maxChars` 为0表示不限长度。拦截优先于替换。替换后再次检查，不能通过替换拼出被拦截的文字。匹配区分大小写，拦截同时检查 Unicode NFKC/常见零宽字符归一化版本；不支持正则表达式。

制作第二个插件：复制此目录，修改 manifest.json 的 id/name/version 和 rules.json，使用插件中心“导入插件文件夹”。ID 不可与内置插件相同。导入只复制两个 JSON 文件，默认停用，不执行目录内脚本。清单的权限不能声明记忆、文件、网络或系统能力。

接口只处理主对话最终文字与 QQ 最终发送前的文字，不扫描图片、视频、工具回执、工作流进度或子任务预览，也不能撤销此前已执行的工具或已发出的图片。现有安全校验仍优先且在替换后再次执行。详见 docs/PLUGINS.md。
