使用本机已安装的三月七小助手执行任务。请先在小助手 Launcher 完成游戏路径、任务和完成后动作等设置，再选择 March7th Assistant.exe。运行期间游戏可能占用鼠标和键盘；Cupbox 日志中的进程退出码不代表游戏任务已完成，请核对小助手日志。
