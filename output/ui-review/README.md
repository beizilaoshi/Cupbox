桌面集成检查共 28 项通过，包含壁纸深浅联动、控件持久化、取消导入、无效图片保护、原图删除后使用、连续切换、重启恢复及 Logo 和图标加载。系统选图对话框在集成测试中使用模拟返回；图片导入、复制、解码和偏好保存使用真实代码。
